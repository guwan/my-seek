# 第三十一章 荒漠奇遇

烈日炙烤着无垠沙海，李元踉跄地行走在西漠边缘。三天前与刘清音分别后，他按照系统指引向西寻找第二块核心碎片，却在这片死亡之海迷失了方向。干裂的嘴唇渗出丝丝血迹，水囊早已见底，眼前开始出现幻觉般的重影。

【系统能量：12%】
【警告：宿主生命体征下降】

李元抬头望向天空，试图通过太阳辨别方向，却看见远处天际线上升起一道诡异的黄褐色幕墙。那沙暴移动速度快得反常，风暴中隐约闪烁着紫色电光。他转身就跑，但人类的速度在自然伟力面前微不足道。眨眼间，遮天蔽日的沙暴已席卷而至，他只能激活系统仅存的防护能量，将自己裹成一个淡蓝色光茧。

沙粒如子弹般击打在光幕上，紫色电蛇在风暴中游走。就在防护即将崩溃的瞬间，李元瞥见风暴眼中有一座模糊的建筑轮廓，随后便失去了知觉。

"咳...咳咳..."

李元被一阵剧烈的咳嗽惊醒，发现自己半埋在沙丘边缘。系统因能量耗尽自动关机，浑身每一寸骨头都像散了架。远处传来兵刃相交与妖兽嘶吼的声音，他挣扎着爬向声源，翻过沙丘后看到一支二十余人的商队被十几头魔化沙蝎围攻。

这些本该只有狗大小的生物，此刻竟如牛犊般巨大，甲壳上布满紫色魔纹。商队护卫已倒下大半，残余者围成圆阵保护中央的驼车。最引人注目的是阵前一位白衣少年，手持玉箫，音波所过之处沙蝎动作会迟缓片刻，但明显已力不从心。

"坚持住！"李元抓起地上一柄断剑冲下山丘。没有系统加持，他只能靠在地心领悟的火灵之力，剑刃泛起微弱红光。一头沙蝎察觉动静转身扑来，他侧身闪避，断剑精准刺入其复眼。

白衣少年玉箫突然爆发出刺耳尖啸，为李元创造了反击机会。他将全部火灵注入断剑掷出，剑身贯穿沙蝎头颅，在颅内爆裂成一团火焰。

"漂亮！"少年喊道，"但还有十二只！"

正当局势危急，李元怀中突然飞出一物——是刘清音给的剑魄玉符！玉符悬浮半空，释放出数十道剑气，精准贯穿剩余沙蝎的神经节点。魔化生物纷纷瘫软倒地，化为黑烟消散。

白衣少年上前扶起摇摇欲坠的李元："在下白游，多谢兄台..."话音未落，李元便因力竭再次昏迷。

浓郁的药香将李元唤醒，他发现自己躺在舒适的驼车中。自称白游的少年端着药碗进来，脸上带着狡黠的笑："醒了？把药喝了，我可是把压箱底的灵药都拿出来了。"

李元接过药碗时，系统突然自动重启，检测到药碗边缘有监测符文。他假装没发现异样一饮而尽，白游眼中闪过一丝讶异："普通人喝这'九转还魂汤'会痛得打滚，阁下倒是淡定。"

"习惯了。"李元擦擦嘴，突然发难扣住白游手腕，"现在说说，为什么药王谷少主要伪装成游商？"

白游瞳孔骤缩，腰间药囊无风自动——上面绣着的符文与系统界面如出一辙！三根银针瞬间抵住李元咽喉："你怎么知道我的身份？"

"药碗上的监测符文是药王谷独有。"李元松开手，指了指对方腰间的药囊，"而且这个图案..."

白游收起银针，神色复杂地解开药囊取出一块青铜罗盘："这是我三年前在古墓所得，上面的符文无人能解。"李元心脏狂跳——那罗盘分明是系统组件的一部分！他试探性注入一丝系统能量，罗盘立刻亮起微光，投射出一段模糊影像：沙漠深处的一座金字塔。

车外突然传来护卫的惊叫。掀开车帘，只见远处沙丘上站着十几个黑袍人，为首者手持一面黑幡——正是之前遭遇过的司空家修士！更糟的是，系统显示那些黑袍人周围的空间正在扭曲，更多敌人即将通过传送阵到来。

"看来我们有共同敌人。"白游迅速取出三颗丹丸，"吃下去，能暂时改变气息。"他又在驼车周围撒下一圈药粉："幻形散，能迷惑追踪法术一炷香时间。"

"为什么要帮我？"李元低声问。

白游指向逼近的黑袍人："三个月前，药王谷三十六名弟子在西漠失踪。我追查发现，他们都曾被这些黑袍人接触过。"他从怀中取出一块留影石，激活后显示一名弟子临终画面："他们在找...天机阁的..."

黑袍人突然集体结印，黑幡暴涨至十丈高！幡面上睁开无数血色眼睛，紫光所照之处的商队成员纷纷抱头惨叫。

"搜魂魔眼！"白游脸色煞白，"他们要找的是你！"

系统弹出紧急任务，李元握紧断剑："白兄，信我一次。"他指向商队货物中的几坛烈酒。当黑袍人逼近到五十步时，白游玉箫奏响刺耳音波，李元则用最后火灵点燃酒坛抛向黑幡。烈焰吞没幡面的瞬间，系统能量顺着火焰侵入核心，黑幡上的眼睛一个接一个爆裂，黑袍人惨叫着化为干尸。

【任务完成】
【物质分析模块已解锁】

夜深人静时，李元检查新解锁的功能。当扫描白游的药囊时，系统突然警报：

【检测到编号03系统组件】
【完整度：41%】
【最后记录：天机阁遗址】

更令人毛骨悚然的是，模块显示白游的玉佩内部刻着微型阵法——与剑宗禁地发现的监控标记一模一样！李元望着篝火旁熟睡的白游，心中升起无数疑问。沙漠深处，那座金字塔形状的天机阁遗址，或许藏着更多关于系统的秘密。
