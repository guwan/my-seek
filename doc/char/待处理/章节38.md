# 第三十八章 黑市拍卖

血色光柱贯穿天地的异象持续了不到一刻钟便消散无踪，但李元知道这绝非好兆头。三人连夜赶路，终于在黎明前抵达距离葬神坑最近的黑岩城。这座建在悬崖边的灰色城池是修仙界著名的三不管地带，也是通往葬神坑的必经之路。

"先找个地方休整。"刘清音压低斗篷帽檐，"全城都是眼线。"

李元点点头，他的系统扫描显示，城中至少有两成修士身上带着司空家的紫铜指环。更麻烦的是，白子游体内的焚血丹毒素虽已缓解，但强行使用灵力的后遗症开始显现——他的瞳孔时而扩散时而收缩，走路也需要搀扶。

三人刚拐进一条暗巷，前方突然出现四个黑袍修士。李元下意识摸向腰间的断剑，却听为首之人低声道："三位可是要去葬神坑？我家主人能提供帮助。"

刘清音的冰魄剑已出鞘三寸："你家主人是谁？"

黑袍人递过一块玉牌，上面刻着药王谷与玄天剑宗的双重纹章——这是两派联盟的信物！"谷主派我等接应白少主。"黑袍人恭敬道，"请随我来。"

白子游虚弱地摇头："药王谷已经..."

李元突然按住他的肩膀，在掌心写道：「将计就计」。他早就通过系统扫描发现，这些黑袍人腰间暗袋里都藏着司空家的令牌。

"带路吧。"李元故作轻松地说，"我们确实需要补给。"

黑袍人领着他们在错综复杂的巷道中穿行，最终停在一家名为"醉仙楼"的酒肆前。推开厚重的檀木门，里面竟是别有洞天——三层楼高的中庭金碧辉煌，几十张八仙桌旁坐满了形形色色的修士，空气中弥漫着灵酒与欲望混杂的气息。

"三位稍候。"黑袍人躬身退下，"主人马上就到。"

李元借着整理衣袍的机会，将04+05号系统碎片藏进了鞋底夹层。刘清音则暗中观察四周，发现至少有二十双眼睛在偷偷打量他们。最可疑的是顶层那个垂着紫纱的包厢，里面隐约坐着个人影。

"黑市。"白子游咳嗽两声，在李元耳边低语，"这里是西域最大的地下拍卖场。"

话音刚落，大厅灯光突然暗下，只剩中央高台被一束青光笼罩。一个戴着青铜面具的主持人走上台，声音经过法术处理变得嘶哑难辨："今日第一件拍品——玄天剑宗秘传《冰魄剑诀》全本！"

刘清音猛地站起，被李元一把拉住。台上展示的确实是剑宗不传之秘，而且是她这一脉的独门剑诀！

"别冲动。"李元低声道，"看他们接下来要干什么。"

接下来的拍品一件比一件惊人：药王谷的九转还魂丹配方、司空家的紫金令牌、甚至还有一块刻着"天机阁"字样的青铜残片！当那块残片出现时，李元鞋底的系统碎片突然发烫——那分明是另一块系统组件！

"必须拿到它。"李元咬牙道，但随即意识到他们身无分文。

白子游突然按住他的手："别急，好戏才刚开始。"

果然，主持人声音突然提高："下面是今日压轴拍品！"他一拍手，八个壮汉抬着三个铁笼上台，"来自玄天剑宗和药王谷的三位'贵客'！"

灯光大亮，李元这才惊觉周围桌上的人全都站了起来，眼中闪烁着贪婪的光。更可怕的是，他和刘清音、白子游不知何时已中了迷药，四肢开始发软！

"第一位，"主持人掀开第一个笼子的黑布，"药王谷少主白子游！精通百草，血液可解万毒，起价十万灵石！"

白子游被粗暴地拖进笼子，脸色惨白却露出诡异的微笑。李元瞬间明白了他的计划——这是要内部突破！

"第二位，"第二个笼子打开，"玄天剑宗天才弟子刘清音！玉衡剑灵认主，魂魄纯净度甲等，起价三十万灵石！"

刘清音眼中寒光一闪，冰魄剑灵刚要发威，顶层包厢突然射下一道紫光，将她强行压制。李元通过系统看到，那紫光中蕴含着与九幽魔气同源的力量！

"最后一位，"主持人走到第三个笼子前，声音因兴奋而颤抖，"天外来客李元！身怀异宝'系统'，起价...无价！竞拍方式特殊，请各位出示你们的'诚意'！"

笼门打开的瞬间，李元假装瘫软倒地，实则已将系统切换至伪装模式。他被拖进笼子时，趁机扫描了整个拍卖场——顶层包厢里坐着个戴银色面具的男子，腰间赫然挂着剑宗执法堂的令牌！而更令人心惊的是，系统在拍卖台下方检测到强烈的能量反应，那里藏着某种空间传送装置。

竞价很快白热化。白子游被一个蒙面女修以十五万灵石拍下；刘清音则引起激烈争夺，价格飙升至五十万灵石时，顶层包厢突然传出一个冰冷的声音："一百万，外加一块天机盘碎片。"

全场哗然。银面人举起一块蓝色晶体，编号"06"清晰可见！这正是李元他们需要的下一块系统碎片！

"成交！"主持人一锤定音。

轮到李元时，竞拍方式果然不同。十几个买家轮流上台，在他面前展示各种奇珍异宝。有拿九幽魔器来的，有献上美人图的，甚至还有人牵来一头幼年蛟龙！但顶层包厢始终沉默。

最后上台的是个佝偻老者，他颤巍巍地捧出一个小玉盒："老朽愿以'返魂香'交换，可唤醒沉睡千年的魂魄。"

银面人终于开口："加上你的命。"

老者还没反应过来，一道紫光就从包厢射出，将他当场击毙。银面人飘然落下，踩过尸体走到笼前："李元，我们又见面了。"

这声音...李元浑身一震，是莫长老！那个在剑宗禁地之战中本该昏迷的执法堂首座！

"很意外？"莫长老掀开面具，露出半张被魔气侵蚀的脸，"你以为葬神坑才是主上的目标？错了，黑岩城的空间节点才是关键！"他一挥手，拍卖台突然下沉，露出下面巨大的传送阵，"至于你...主上要亲自见见这个'天外来客'。"

李元看到刘清音和白子游已被押到传送阵边缘，而那块06号碎片就挂在莫长老腰间！他暗中激活系统，准备最后一搏，却突然收到一条异常提示：

【检测到主程序干预】
【强制任务更新：进入传送阵】
【奖励：系统完整度提升至85%】

这不对劲！系统从未如此强硬地下达指令。李元犹豫的刹那，莫长老已命人将他也押向传送阵。经过展示台时，他假装踉跄，一把抓住那块天机阁青铜残片。

"找死！"莫长老一掌劈来。

李元硬接了这一击，口中鲜血狂喷，却成功将残片塞入袖中。接触的瞬间，系统突然自动读取了残片中的数据，海量信息涌入脑海——那是天机阁最后时刻的记录！画面中，司空晦的前世正站在一个巨大的金色光球前，狞笑着说："...系统主程序早已被污染...沈柯寒到死都不知道..."

信息流突然中断，李元已被推入传送阵。莫长老站在阵外，举起06号碎片："主上在葬神坑等你。"他将碎片嵌入阵法核心，"带着你的系统，来完成最后的仪式吧！"

强光亮起，李元最后看到的，是莫长老那张半人半魔的脸上，浮现出与司空晦如出一辙的诡异微笑。而在系统深处，一段被标记为【主程序】的代码，正在悄然改变着最终任务的参数...

【新任务已载入：协助完成九幽降临仪式】
【备注：此指令优先级高于一切】
