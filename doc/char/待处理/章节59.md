# 第五十九章 创造者之墓

07号的救援光束将三人拽出深渊，却落入更深的陷阱。穿过崩塌的岩壁后，李元惊讶地发现自己站在一条金属走廊里——墙壁材质与海底基地完全相同！

"这是...创造者的研究所？"李元摸着刻有符文的金属壁，系统自动翻译出【第13号实验区】的字样。

白子游瘫倒在角落，胸口的紫色晶体已碎裂大半。刘清音试图用灵力为他疗伤，却被反震得后退数步："他体内有两种相斥的能量！"

"01号核心碎片在净化魔气。"07号检查着白子游的状况，机械义眼闪烁着蓝光，"但过程不可逆。"他递给李元一块数据板，"我们没多少时间了，00号已经启动最终程序。"

数据板显示着十二道光柱的实时状态，其中六根完全变成紫黑色。更令人不安的是，代表归墟的光柱正在与药王谷、剑宗的光柱形成三角能量场。

"时空锚点。"07号指向三个交汇处，"司空晦的三份魂魄即将合一。"

走廊尽头突然传来齿轮转动的轰鸣。07号脸色骤变："他们发现我们了！"他推开侧面一道暗门，"走这里！"

暗门后是向下的螺旋阶梯，深不见底。众人刚踏入，上方就传来爆炸声！07号殿后，不断在阶梯上布置干扰装置："这里曾是创造者的秘密实验室，00号也不知道全部构造。"

下行了约莫半小时，空气变得冰冷刺骨。阶梯尽头是一扇青铜门，上面镌刻着十二实验体的浮雕。李元注意到09号的位置空着——正好是他现在的站位。

"身份验证。"07号示意李元上前，"只有你能打开。"

李元将手按在凹槽处，系统突然弹出从未见过的界面：【最终协议验证中...DNA匹配度99.9%...欢迎回来，09号】。青铜门无声滑开，露出一个圆形大厅。

大厅中央悬浮着十二具水晶棺，呈星状排列。每具棺椁都连接着复杂管线，汇聚到中央控制台。控制台上方，沈柯寒的全息投影正在循环播放：

"如果你们看到这段记录，说明计划出现了最坏情况。"影像中的沈柯寒面容憔悴，"系统真正的目的不是培养救世主，而是筛选容器——能够承受我全部记忆与修为的容器。"

李元如遭雷击。这就是为什么系统会选择他？为什么所有实验体都与他相貌相似？

控制台突然激活，投射出更多画面：沈柯寒在实验室培养胚胎，每个都带有他的基因片段；少年实验体们接受残酷测试，失败的被当场销毁；最后的画面是12号实验体——一个银发少女被注入某种液体后，突然爆发出耀眼光芒...

"唯一成功的12号..."07号轻声说，"就是寒玥剑灵真正的主人。"

刘清音猛地转头："什么？"

没等07号解释，大厅突然剧烈震动！某个水晶棺的管线断裂，喷出紫色雾气。07号迅速操作控制台："00号在攻击外部防御，我们必须加快速度。"

控制台升起一个小型金属箱，打开后里面是一口巴掌大的青铜钟。"镇魂钟，"07号取出递给李元，"能暂时压制司空晦的魂魄，但每次使用都会消耗使用者寿命。"

李元接过铜钟的瞬间，系统突然发出警报：【检测到时空异常】！全息影像扭曲变形，沈柯寒的画面突然变成一段陌生记录：

黑暗的实验室里，满脸是血的沈柯寒正对着监控说话："记住，真正的叛徒是..."画面突然被干扰，隐约可见一个穿白大褂的身影站在他身后。干扰消失后，沈柯寒的遗言变成了："...07号将协助你们完成最终任务。"

最诡异的莫过于——那个白大褂转身时，露出的赫然是李元自己的脸！

"这不可能..."李元倒退半步，"那段记录被篡改过！"

07号的机械义眼闪过一丝红光："时间不多了，00号已经..."他的话戛然而止，因为白子游突然暴起，紫晶化的右手直插07号后背！

"07号小心！"刘清音挥剑斩向白子游手腕，却见07号仿佛早有预料般侧身避开，反手一记能量波将白子游击飞。

动作流畅得...像是排练过千百遍。

白子游撞在水晶棺上，吐出一口紫黑色血液。他艰难地抬头，独眼中竟流露出一丝清明："李元...快走...这是陷..."

一根紫色能量矛突然从天花板刺下，贯穿他胸膛！07号立即启动防御屏障，却见更多能量矛如雨般落下。

"00号找到我们了！"07号拽着李元冲向控制台，"启动紧急传送！"

刘清音想去救白子游，却被突然出现的水晶棺挡住去路。濒死的白子游用最后力气指向某个方向："创造者...真正的墓在..."他的身体突然被紫火吞噬，灰烬中只余一块青色晶体。

07号强行启动传送程序："没时间了！"蓝光笼罩了李元和刘清音，却独独漏了他自己。

"07号！"李元伸手想拉他，却抓了个空。

"记住，"07号在紫光中露出诡异的微笑，"不要相信..."传送光芒吞没了后半句话。

天旋地转后，李元和刘清音跌落在荒芜的山顶。远处十二道光柱贯通天地，而他们面前是一座简陋的石碑，上面刻着：【沈柯寒与爱徒凌霜长眠于此】。

寒玥剑突然自动出鞘，剑尖轻触墓碑。令人震惊的是，碑文下方渐渐浮现出隐藏文字：【真相在时空中，钥匙在血脉里】。

"这是..."刘清音抚摸着新出现的文字，"凌霜师姐的字迹。"

李元体内的系统突然自主激活，投影出一段加密信息：【检测到永恒之血，最终协议解锁】。他的左手不受控制地按在墓碑上，鲜血渗入石缝——

整座山峰开始震动！墓碑下沉，露出向下的阶梯。深渊之底，隐约可见蓝色光芒...
