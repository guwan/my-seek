# 第一百二十章 新的开始

春雨淅淅沥沥地下了一整夜，清晨的逍遥居茶馆弥漫着龙井的清香。李元将"营业中"的木牌挂到门口，顺手拂去门框上昨夜新结的蜘蛛网。这只蜘蛛很特别——八条腿上都带着金色的环纹，网上织出的图案酷似微型阵法。

"看来今天会有客人。"刘清音从后院走来，手腕上的剑痕胎记微微泛着蓝光。三年来，这个胎记已经成为他们预测奇异事件的晴雨表。

李元点点头，目光扫过柜台上那叠泛黄的手稿——《逍遥仙途》的最后一章始终没能写完。每次提笔，总会有突发事件打断。最奇怪的是，手稿会自行增添一些他们没写过的内容，比如前天突然出现的"红鞋观察者07号"的详细描述。

"我去准备些茶点。"刘清音转身时，发髻上的白玉兰簪子闪过一道微光。这只簪子是茶馆开业那天突然出现在柜台上的，簪头刻着几乎不可见的"S.K.H"字样。

茶馆刚开门不久，熟客们便陆续到来。退休的周老师照例坐在靠窗位置研究他的星象图；总穿着红裙子的幼儿园老师小苏带着一群孩子来听故事；就连镇上的老猫"阿玄"也准时出现在它的专属坐垫上——这只猫从不吃鱼，却对刘清音泡的茶情有独钟。

"李老板，"周老师神秘兮兮地招手，"昨晚我观星时发现件怪事，北斗七星的勺柄位置和古籍记载完全相反！"

李元沏茶的手微微一顿。这已经是本周第三个报告天体异常的人了。前天邮差说月亮上有蓝光闪烁，昨天渔夫声称在湖心看到倒悬的宫殿。他正想回应，门口的风铃突然无风自动，发出急促的声响。

所有客人同时转头看向门口，但那里空无一人。只有阿玄弓起背，金色竖瞳紧盯着门外的薄雾。

"要来了。"刘清音轻声说，手指无意识地在空中划出一道符咒的轨迹。自从放弃守护者身份后，他们只保留了最基础的能力，但某些本能已经刻进灵魂。

雾气中传来脚步声，由远及近，每一步都让茶馆的地板微微震动。客人们面面相觑——明明听起来像是有千军万马逼近，门外却依然空荡荡的。

脚步声在门口戛然而止。门帘自动掀起，一个穿灰色道袍的老者迈步而入。李元瞳孔骤缩——来人竟是沈柯寒教授！或者说，是一个长得和沈教授一模一样的老人。

"好久不见，守护者们。"老人微笑，声音却比记忆中的沈教授更加空灵，"或者说，前守护者们。"

茶馆里的时间仿佛凝固了。周老师的茶杯悬在半空，水滴静止；孩子们的欢笑声戛然而止，像被按了暂停键；就连阿玄也定格在跃起的瞬间。

刘清音的手按上剑痕胎记："你不是沈教授。他是人类，而你..."

"是世界意志的具象化。"老人和蔼地点头，"沈柯寒是我的上一个载体。现在，我需要新的代言人。"他的目光扫过静止的客人们，"他们都很合适。"

李元不动声色地站到刘清音身前："我们已放弃守护者职责。按照契约——"

"契约依然有效。"老人——世界意志打断他，"我只是来送礼物。"他指向柜台上的手稿，"《逍遥仙途》该有个结局了。毕竟..."他的身影开始透明化，"所有的故事都值得一个美好的收尾。"

时间重新流动。客人们继续着刚才的活动，似乎没人注意到刚才的插曲。只有阿玄警惕地环顾四周，最后跳上柜台，用爪子按住了手稿的最后一页。

李元走过去，发现稿纸上浮现出新的字迹——是他们从未写过的结局章节。更奇怪的是，故事里的情节竟然包含了他们这三年在茶馆解决的所有奇异事件，包括今天早上发生的事！

"看来我们的人生成了一本书。"刘清音苦笑着翻开最后一页，那里画着一个莫比乌斯环图案，环中写着"未完待续"四个小字。

门口的风铃再次响起。这次走进来的是个陌生的年轻人，背着旅行包，浑身湿透。

"抱歉打扰，"年轻人摘下帽子，露出与李元有七分相似的面容，"我听说这里能解决...特殊的问题？"他从包里取出一个青铜罗盘，指针正疯狂旋转。

李元和刘清音对视一眼。这个罗盘他们太熟悉了——正是当年修仙世界白子游的法器！而年轻人脖子上挂着的玉坠，分明是药王谷掌门信物。

"先喝杯热茶吧。"刘清音温和地说，示意年轻人坐下，"说说你遇到了什么怪事。"

年轻人刚要开口，后院的古井突然发出嗡鸣，井水溢出形成一道水幕。水幕中浮现出无数画面：机械城的06号机械体正在发送求救信号、某个世界线的琉璃转世歌手被黑衣人追踪、甚至还有现代世界实验室的年轻李元和刘清音在进行危险的实验...

"看来'放手'不等于结束。"李元叹了口气，从柜台下取出一把古旧的钥匙——那是他们封印大部分力量时，唯一保留的物品。

刘清音已经为年轻人倒好了茶："欢迎来到逍遥居。这里专门解决无法用常理解释的事件。"她手腕上的剑痕金光流转，"尤其是...跨时空的麻烦。"

年轻人惊讶地看着茶水中的倒影——那不是他自己的脸，而是一个古代剑修的模样！当他抬头时，发现茶馆的墙壁上挂满了来自不同时代的器物：星际联盟的勋章、修仙界的符箓、甚至还有未来科技的蓝图。

阿玄跳上年轻人的膝盖，喵了一声。这一声在三人耳中却变成了清晰的话语："第七枚芯片在他背包夹层里。"

窗外，雨停了。阳光穿透云层，照在柜台的手稿上，"未完待续"四个字闪闪发亮。远处的白玉兰树上，两朵并蒂花同时绽放，隐约形成守护者徽章的形状。
