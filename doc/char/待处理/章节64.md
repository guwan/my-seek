# 第六十四章 系统真名

黎明前的剑宗静得可怕。李元盘坐在密室中央，面前摆放着07号送来的金属箱。十二枚芯片在水晶柱的蓝光照射下泛着冷芒，如同十二只窥探的眼睛。

"系统完整度89%..."李元轻触太阳穴，界面投影在视网膜上，"还差最后一块。"

刘清音正在为琉璃疗伤，鲛人公主额头的金纹已经恢复银白，但瞳孔仍偶尔闪过紫光。"00号在我记忆深处留了信息。"她虚弱地指向东方，"归墟最底层...有创造者留下的..."

寒玥-凌霜的虚影飘到金属箱前："这些芯片必须重新融合。"她指尖轻点，十二枚芯片悬浮成环，"但缺少核心枢纽。"

李元看向水晶柱——这根从寒玥剑化形的柱体正是系统最初的原型。他深吸一口气，将柱体置于芯片环中央。

"你确定吗？"刘清音按住他的手，"一旦启动，可能再也无法回头。"

李元望向窗外的血色残月："我们还有选择吗？"

当水晶柱与第一枚芯片接触时，整个密室突然亮如白昼！李元感到一股庞大信息流涌入脑海，系统提示疯狂闪烁：

【核心碎片重组中...90%...】
【最终权限解锁】
【系统真名确认：文明方舟】

全息投影自动展开，展现出令人震撼的真相：系统并非单纯的修炼辅助工具，而是沈柯寒为应对"大崩塌"设计的文明火种保存装置！十二实验体各自承载着不同领域的知识库，而李元体内的09号核心，正是最重要的"决策中枢"。

"难怪司空晦要集齐所有碎片..."琉璃的声音发抖，"他想要重启整个人类文明！"

投影切换至沈柯寒的遗言。这位创造者看起来比记忆中苍老许多："无论你是谁，当你看到这段记录时，说明我的计划已经失败。"他疲惫地揉着眉心，"我不是第一个尝试者，也不会是最后一个..."

最震撼的画面出现了：实验室深处排列着数十具培养舱，每个里面都是沈柯寒的克隆体！而最后一个舱体标签写着【第49代转世体：李元】。

"你是...创造者的转世？"刘清音瞪大眼睛。

李元还未来得及消化这个信息，投影中的沈柯寒突然压低声音："小心第十二个影子！它不是实..."影像突然被干扰，切换至另一段记录。

这次是年轻的沈柯寒在训斥某个模糊人影："我警告过你不要接触00号！现在它已经污染了整个第12区！"那人影低声回应："老师，您太保守了...人类需要进化..."

记录再次中断，系统弹出新提示：【最终功能解锁：规则模拟】。描述显示这项能力可以短暂修改小范围内的物理法则，但代价是加速系统能量消耗。

"这就是创造者对抗大崩塌的方法..."寒玥-凌霜若有所悟，"不是对抗，而是重塑规则。"

密室突然剧烈震动！琉璃惊恐地指向窗外："月食...提前开始了！"

原本还有三天的期限，此刻天空却已出现黑色缺口！血色月光被一点点吞噬，而剑宗上空的金色大网正以肉眼可见的速度消散。

"是司空晦！"刘清音召出光剑，"他在强行加速进程！"

李元迅速将十二枚芯片嵌入水晶柱。当最后一枚归位时，整个柱体化作流光没入他的胸口！系统界面彻底革新，无数陌生功能解锁，但最引人注目的是中央闪烁的红点——显示着00号本体的实时位置：归墟海眼。

"我们得立刻..."李元的话戛然而止，因为系统突然检测到异常：【检测到第十二实验体能量特征】。

密室角落的阴影诡异地蠕动起来，渐渐凝成一个人形。所有人都绷紧神经——第十二实验体本该是寒玥剑灵的前身，早已在三千年前陨落！

阴影完全成形，露出与李元七分相似的面容，但眼神沧桑如百岁老人。"终于见面了，09号。"他的声音带着奇异的回响，"或者说...第49代的我？"

"创造者？"李元不敢相信自己的眼睛。

人影摇头："我是第12号实验体，也是第一个成功载体。"他指向自己半透明的身体，"你看到的只是残留在系统中的记忆投影。"

寒玥-凌霜突然剑指12号："不对！我在凌霜师姐记忆里见过你...你是..."

12号微笑："裘幽最完美的作品，对吗？"他身影突然闪烁，"时间不多，听好：司空晦不是敌人，他只是在执行我的备用计划。"

这个颠覆性的宣言让所有人呆立当场。12号继续道："当年我预见到大崩塌无法阻止，于是将计就计..."他的身影开始消散，"去找07号...他知道..."

投影完全消失前，李元注意到12号的右手缺了一根小指——与魔神手指的尺寸完全吻合！

天空传来震耳欲聋的雷鸣，月食已过半。李元当机立断："清音和寒玥守住剑宗，我和琉璃去归墟！"

"不行！"刘清音抓住他的手臂，"这明显是陷阱！"

李元启动新解锁的"规则模拟"，在掌心创造出一个微型黑洞："正因如此，才更要去。"他看向琉璃，"00号在你记忆里留了什么？"

琉璃的银发无风自动："一首坐标歌谣...指向归墟的'门'..."

时间不容耽搁。分别前，寒玥-凌霜将一块冰晶碎片交给李元："带上这个...凌霜师姐的记忆..."碎片中隐约可见某个海底洞窟的景象。

当李元和琉璃御剑冲向东方时，剑宗上空的金网彻底破碎。司空晦的完全体发出胜利的咆哮，化作紫黑流星坠向归墟方向...
