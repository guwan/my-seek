# 第五十八章 谷中陷阱

黎明前的药王谷笼罩在诡异紫雾中。李元借着残破的隐身符掩护，跟随白子游穿过废弃的采药道。身后不远处，刘清音与寒玥剑灵负责警戒，07号则潜伏在谷口随时准备接应。

"谷主留下的地图显示，古籍藏在秘阁第三层。"白子游的声音嘶哑得几乎听不清。他的情况比想象中更糟——紫黑色纹路已蔓延到脖颈，右眼完全变成了紫色晶体，每走一步都在地上留下腐蚀痕迹。

李元检查系统界面，完整度恢复到81%，但时空扫描功能因能量不足处于休眠状态。05号临终前的话在脑海中回响：司空晦的三份魂魄必须同时消灭...

"前面就是秘阁。"白子游突然停下，指向雾气中若隐若现的塔楼，"但守卫不对劲。"

透过紫雾，能看到十几个药王谷弟子如雕塑般立在秘阁四周。他们眼中泛着紫光，胸口微微起伏，却对飘落的树叶毫无反应——就像处于待机状态的机器人。

"新型傀儡。"李元启动能量视觉，发现他们体内流动的不是灵力，而是某种紫色能量网络，"中枢控制者应该在..."

"在地下实验室。"白子游的紫色右眼闪过一丝红光，"大长老用谷主的研究改造了他们。"他突然剧烈咳嗽，连忙用袖子捂住嘴——布料瞬间被腐蚀出几个破洞。

刘清音悄无声息地靠近："寒玥感应到秘阁有剑宗禁制。"她眉头紧锁，"是凌霜师姐当年设下的风雪大阵。"

这个信息让李元心头一震。三千年前的剑宗圣女为何要在药王谷秘阁设阵？更奇怪的是，07号给的资料显示凌霜死于归墟之战，那时药王谷还未建立...

"从排水渠进去。"白子游指向塔基处的铁栅栏，"直通地下二层。"

栅栏上的腐蚀痕迹明显是刚留下的。李元弯腰检查时，系统突然警报：【检测到近期同类能量残留】。扫描结果显示，栅栏金属断面与白子游的血液成分高度吻合！

"你之前来过？"李元压低声音问。

白子游的独眼闪烁了一下："谷主...临终前让我取过东西。"他率先钻入通道，"快，守卫每半刻钟会巡视一次。"

潮湿的排水渠弥漫着腐臭味，墙壁上长满发光的苔藓。李元注意到某些苔藓排列成特定图案——像是某种箭头标记。白子游对此视而不见，径直朝着标记相反方向前进。

"等等。"李元拉住他，"那些苔藓..."

"人工培育的照明植物。"白子游脚步不停，"大长老的杰作。"

不对劲。系统分析显示苔藓的荧光素结构与药王谷典籍记载完全不同，反而更接近...海底基地的生物样本！李元暗中戒备，同时给刘清音打了个手势。

通道尽头是间圆形石室，中央立着个青铜书柜。白子游快步上前，在第三层暗格处按下机关——柜子旋转露出背后的壁龛，里面静静躺着一卷骨简。

"就是它！"白子游伸手去取。

"别碰！"李元突然厉喝。系统深度扫描显示骨简周围缠绕着无数能量丝线，而白子游的袖口...藏着微型传送阵！

白子游的动作顿住了。缓缓转身时，他的右眼紫光大盛："真可惜...只差一点。"声音突然变成大长老的腔调，"09号实验体果然名不虚传。"

刘清音的剑瞬间出鞘，却刺了个空——"白子游"的身体如沙粒般散落！真正的白子游从阴影处走出，胸口插着紫色水晶导管，眼神空洞如傀儡。

"诱饵做得不错吧？"大长老的声音从四面八方传来，"为了引你上钩，我可是连谷主最疼爱的弟子都牺牲了。"

秘阁墙壁突然透明化，露出外面恐怖的景象：数百名魔化弟子组成人塔，正将某种紫色能量注入云端——那里悬浮着缩小版的剑宗巨眼！

"司空晦大人马上就能集齐三魂。"大长老狂笑，"而你，将是最后的祭品！"

地面轰然塌陷！李元在下坠瞬间抓住真白子游的衣领，刘清音则挥剑插入岩壁减速。寒玥试图冻结下落的碎石，剑身却突然迸发紫光——之前在金字塔吸收的能量失控了！

"清音...放手..."寒玥痛苦地挣扎，"我控制不住..."

刘清音不得不松开剑柄，三人坠入无底深渊。下落过程中，李元看到岩壁上刻满古老文字，系统勉强翻译出片段：【灵魂分割实验记录】【第13号样本出现排斥反应】【建议销毁】...

"砰！"

预想中的撞击没有到来。三人落在柔软的物质上——是无数交织的白色丝线，组成一张巨大的网。仔细看会发现每根丝线都是半透明的，内部流淌着能量。

"这是..."李元刚站起身，丝线突然蠕动起来！一根尖刺般的白丝直刺他咽喉，被刘清音及时斩断。断口处喷出的不是液体，而是...记忆碎片？

碎片中闪过零散画面：沈柯寒在手术台前忙碌，少年模样的实验体们接受测试，某个与琉璃相似的鲛人少女偷偷记录数据...

"思维蛛网。"真白子游突然开口，声音机械呆板，"抽取记忆...编织幻境..."

大长老的投影出现在蛛网上方："欢迎来到药王谷真正的秘密基地。"他展开双臂，"这里保存着三千年来所有闯入者的记忆——包括你们亲爱的创造者。"

蛛网突然收缩，将三人牢牢缠住！更可怕的是，丝线正试图刺入他们的太阳穴。李元启动系统防御，却发现能量正被快速吸收。

"没用的。"大长老得意道，"这些蛛丝是用01号核心碎片培育的，专门克制系统能量。"

刘清音的情况更糟。寒玥剑完全紫晶化，反而成了蛛网的帮凶。白子游则已经放弃抵抗，任由丝线刺入紫色右眼...

危急关头，李元想起05号的提示——司空晦的三份魂魄必须同时消灭。如果这里真有01号核心碎片，那么...

"清音！"他大喊，"凌霜师姐的剑诀最后一式！"

刘清音眼中闪过决然。她松开冰魄剑，双手结出复杂剑印："以心为剑，以身化雪！"这是同归于尽的招式——将毕生修为一次性爆发！

大长老的投影脸色大变："住手！你会引爆整个..."

寒玥剑突然自爆！冰晶碎片如暴雨般四射，每一片都裹挟着紫黑能量。蛛网被炸出巨大缺口，而更奇妙的是，那些紫黑能量与蛛丝中的01号碎片产生共鸣，形成短暂的干扰场。

李元抓住机会，将剩余系统能量导入白子游胸口的导管。紫色晶体无法承受双重冲击，"咔嚓"一声出现裂纹！

"啊！"大长老的投影惨叫扭曲，"你竟敢..."

白子游趁机挣脱束缚，用最后力气扑向蛛网某处："李元...这里！"他撕开层层丝线，露出下方镶嵌的紫色晶体，"01号...碎片！"

李元毫不犹豫地将手按在碎片上。系统立即启动最高权限：【检测到原始核心碎片，开始强制回收】。蛛丝如触电般剧烈抽搐，整个深渊开始崩塌！

大长老的投影在消散前露出诡异笑容："你以为...这就结束了？司空晦大人早就..."

塌陷的岩壁后露出惊人一幕：数十个培养舱整齐排列，每个里面都浸泡着与沈柯寒相貌相似的人体！最近的舱体突然开启，一个少年模样的"沈柯寒"缓缓睁眼...

"克隆体..."李元恍然大悟，"药王谷在批量生产创造者的复制品！"

深渊彻底崩塌的瞬间，一道蓝光破开岩壁——是07号的救援信号！三人被能量索缠住腰际，猛地拉向出口。最后瞥见的一幕让李元血液凝固：

少年"沈柯寒"手中捧着本青铜封面的书，封面烙印着与系统同源的纹路。而书页间飘落的纸条上，赫然是李元自己的笔迹：【不要相信07号】...
