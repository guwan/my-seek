# 第四十四章 记忆复苏

冰魄剑的寒芒在琉璃咽喉前寸许停住，剑灵虚幻的身影浮现在剑身上方，眼中燃烧着千年不灭的怒火。珊瑚洞穴内的空气仿佛凝固了，所有人都被这突如其来的变故惊得怔在原地。

"剑灵前辈！"刘清音最先反应过来，手指结印试图收回佩剑，"琉璃是我们的同伴！"

剑灵充耳不闻，剑尖又向前递了半寸，在鲛人公主雪白的脖颈上划出一道血线："三千年前，若非沈柯寒养女泄密，九幽魔尊怎能找到天元子闭关之地？"它转向李元，声音如金铁交鸣，"09号，你也被她骗了！"

李元手中的金属球突然发烫，投影文字变换成红色警告：【检测到剑灵核心代码异常！来源：裘幽改造！】。这个提示让他浑身一震——难道剑灵也被00号污染了？

"等等！"白子游突然挡在琉璃身前，药王谷秘传的金针在指间闪烁，"剑灵前辈，您说琉璃泄密，可三千年前她根本不存在！我们刚刚在海底古城亲眼看到，沈柯寒的养女是雕像所刻之人，不是现在的琉璃！"

这番话说得剑灵微微一滞。李元抓住机会，将金属球贴近冰魄剑。球体表面突然伸出无数纳米级细丝，刺入剑身。剑灵发出痛苦的嘶吼，一段被加密的记忆数据通过细丝传输到李元的系统中：

——漫天火光的战场上，酷似刘清音的女子（裘幽）将一枚紫色晶片刺入剑灵核心。晶片上刻着"00"字样。

"看到了吗？"李元额头渗出冷汗，"您被裘幽动过手脚！"

剑灵剧烈颤抖，冰晶般的躯体出现裂纹。刘清音趁机夺回控制权，强行将剑灵收回剑鞘。琉璃瘫坐在地，手指颤抖着触摸颈间伤口，珍珠的光芒变得黯淡。

"我...我脑海中多了些记忆碎片。"她声音发飘，"看到自己站在沈柯寒身边，看着他往09号培养舱注入某种金色液体..."

这句话像钥匙般打开了李元脑海中的某道锁。剧痛如潮水般袭来，他跪倒在地，系统界面疯狂闪烁。无数记忆碎片从意识深处浮起，如走马灯般闪过：

——实验室里，银边眼镜的教授（年轻时的司空晦？）将芯片插入他的后颈。
——培养舱中苏醒，看到十二个舱体环绕着自己。
——沈柯寒抚摸他的头说："09号，你是我最成功的作品。"
——裘幽冷笑的脸："你以为创造克隆体就能阻止00号苏醒？天真！"

记忆洪流太过汹涌，李元七窍渗出鲜血。刘清音慌忙扶住他，却被突然爆发的能量场弹开。金属球自动分解，化作液态金属包裹住李元全身，形成一副奇异的铠甲。

【记忆锁解除】
【真实身份确认：09号实验体】
【系统全称：文明火种传承装置】

随着电子音在脑海中回荡，李元看到系统界面发生了翻天覆地的变化。原本游戏般的任务系统消失不见，取而代之的是复杂的多维控制台。最中央显示着十二个光点，其中四个亮着蓝色（02、04、05、08），一个红色（06在司空家手中），其余七个灰色。

"原来如此..."李元的声音透过金属面甲传出，带着机械质感，"系统根本不是辅助修仙的金手指，而是沈柯寒设计的文明保存装置。十二个实验体对应十二个核心功能，我是09号——知识传承模块。"

白子游脸色煞白："所以你不是穿越者？只是被植入了现代人记忆的克隆体？"

这个问题让洞穴内一片死寂。李元揭开面甲，露出苦笑："不，我是真正的李元。沈柯寒找到平行世界的我，将我的意识复制到09号克隆体上。"他指向太阳穴，"因为只有来自科技文明的思维模式，才能完全激活知识传承模块。"

刘清音突然拔剑指向洞穴深处："谁？！"

阴影中走出一个意想不到的身影——金乌！它第三只眼布满血丝，羽毛脱落大半，显然经历了一场恶战。"总算找到你们了。"它声音嘶哑，"剑宗彻底沦陷，魔神手指完全苏醒。更糟的是..."金乌吐出一块留影石，"看这个。"

激活留影石，浮现出司空晦的身影。他站在剑宗废墟上，身后悬浮着巨大的黑色手掌。最令人毛骨悚然的是，手掌中心那只紫色眼睛上方，缓缓浮现出一个模糊的人形虚影——与海底古城影像中的裘幽一模一样！

"九幽魔尊只是傀儡，真正的幕后黑手是裘幽。"金乌的第三只眼看向琉璃，"而她，一直在寻找沈柯寒的养女转世。"

琉璃的珍珠突然发出刺目强光，一段全息投影自动播放：沈柯寒濒死时将一枚种子般的光点注入珍珠："琉璃，带着你的记忆核心转世。当09号找回所有组件时，你会想起一切..."

投影中的琉璃与现在的琉璃逐渐重叠，记忆如决堤洪水涌入她的意识。她抱住头痛苦呻吟，鱼尾上的鳞片片片竖起，发出金属般的脆响。

"我不是第三代鲛人公主..."她声音变得空灵，"我是第一代琉璃的克隆体，记忆被封印在珍珠里..."

李元系统突然警报大作：【检测到00号能量激增！位置：剑宗！倒计时：72小时！】与此同时，他脑海中闪过一个可怕的想法：如果裘幽控制着00号，而00号需要十二个组件激活，那司空家为何不急着收集所有碎片？

除非...他们已经有了替代方案！

"金乌前辈，"李元声音发紧，"剑宗地下的魔神手指，是不是在吸收剑宗弟子的精血？"

三足金乌的瞳孔缩成针尖："你怎么知道？那些被控制的弟子排着队跳入地缝，血肉被..."

话未说完，珊瑚洞穴突然剧烈震动，海水从缝隙中喷涌而入。金乌展开残破的翅膀："快走！南海归墟的封印被触动了！"

众人冲向洞口，却被眼前的景象震撼——海面上空，十二道紫色光柱贯通天地，形成一个正十二边形。每道光柱中隐约可见一块系统碎片，包括莫长老夺走的06号。而中心位置，剑宗方向的天空已经变成诡异的紫色，一只巨大的眼睛正在云层中缓缓睁开。

"他们用血肉能量替代缺失的组件！"李元瞬间明白过来，"裘幽要强行激活00号！"

白子游突然抓住李元的手臂："等等，如果裘幽需要十二个组件，而你本身就是09号组件的人形容器..."他脸色惨白，"那其他实验体呢？"

这个问题让所有人不寒而栗。李元调出系统刚解锁的数据库，十二个实验体资料依次浮现。当看到03号时，他浑身一震——画面中是个与白子游有七分相似的少年，标注着"医毒双绝模块"！

"子游，你..."李元难以置信地看向好友。

药王谷少主苦笑："看来我体内的07号子系统不是偶然。"他撕开衣襟，心口的"07"纹路正在发光，"父亲...不，司空晦早就计划好了一切。"

最惊人的发现来自琉璃。当李元查看08号实验体资料时，系统显示：【08号：海洋生态模块。状态：与鲛人族基因融合成功。载体：琉璃（第一代）。备注：唯一保留记忆的克隆体。】

"所以海底古城的雕像真的是你。"刘清音轻声道，"但为什么剑灵会称你为叛徒之女？"

琉璃刚要回答，金乌突然厉声警告："小心水下！"

海面炸开，五头魔化蛟龙破浪而出，每头头顶都站着一名司空家修士。为首的正是莫长老，他手中06号碎片与李元体内的系统产生强烈共鸣，剧痛几乎让人昏厥。

"09号！"莫长老的声音经过法术放大，"主上有令，交出08号组件，饶你不死！"

李元突然明白过来：琉璃的珍珠不是08号组件，她本人就是活体组件！司空家需要的是她体内的核心代码。想到这里，他立即启动系统新解锁的"协同防御"功能，一道蓝色光罩笼罩住众人。

"清音，带琉璃先走！"李元通过同心印传递信息，"去归墟最深处，那里有沈柯寒留下的最后防线！"

刘清音刚要反对，突然理解了李元的计划——既然裘幽能用血肉能量替代缺失组件，他们也可以用计策反将一军。她假装愤怒地瞪了李元一眼，抓起琉璃御剑而起："叛徒！我看错你了！"

这出戏骗过了莫长老。他冷笑一声，指挥两头蛟龙追去，剩余力量全部压向李元三人。金乌喷出太阳真火阻敌，白子游则洒出药王谷秘传的毒雾。

激战中，李元发现系统新增的"文明火种"功能需要庞大能量启动。而能量来源赫然是...其他实验体！他看向白子游，一个艰难的决定在心中成形。

"子游，"他挡下一道紫雷，"如果我要借用你体内的07号能量..."

"早该如此。"白子游露出解脱般的笑容，"我受够做别人的棋子了。"

两人背靠背站立，李元将系统连接请求发送过去。白子游体内的07号纹路光芒大盛，化作数据流涌入李元系统。药王谷少主的身体逐渐透明，最后时刻，他塞给李元一块玉简："给我父亲...告诉他...我原谅..."

话音未落，白子游化作光点消散，只在李元手中留下一枚小巧的青色晶体——纯净的07号组件核心。系统完整度瞬间飙升至92%，"文明火种"功能终于完全启动。

金乌目睹这一切，第三只眼流下血泪："值得吗？"

李元没有回答。他看向刘清音离去的方向，通过系统远程激活了琉璃体内的08号代码。南海深处顿时亮起十二道蓝光，与司空家的紫光分庭抗礼。

"现在，"李元的声音冷静得可怕，"该让裘幽见识下真正的文明火种了。"

他展开双臂，系统全功率运行。以07号组件为引，所有已获得的组件数据开始重构。天空中浮现出巨大的全息投影——那是沈柯寒留下的最后讯息：

"致所有火种携带者：当你们看到这段信息时，说明裘幽已经控制了00号。但记住，00号本是我设计的囚笼，用来封印真正的灭世者——她自己！"

投影中的沈柯寒转向镜头，眼神仿佛穿透三千年时光直视李元："09号，你是我最成功的作品。因为你不仅有我的知识，还有来自异界的灵魂。现在，是时候唤醒其他实验体了..."

随着这段话，李元脑海中浮现出十一个模糊的身影——那是其他实验体的实时位置。最令他震惊的是，00号的位置显示竟然在...他自己的意识深处！
