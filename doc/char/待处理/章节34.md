# 第三十四章 古墓秘境

通道内的空气带着千年未散的尘土味，每走一步都会激起细小的尘埃。李元走在最前面，手中托着一团微弱的系统灵光，照亮前方不足三米的路径。白子游拖着虚弱的身体紧随其后，时不时回头查看昏迷的林小凡是否被妥善安置在洞口隐蔽处。

"这绝不是天然形成的。"白子游的手指擦过通道墙壁，上面覆盖着精细的纹路，"看这些刻痕，像是某种机械挖掘的痕迹。"

李元启动系统的物质分析模块，墙壁成分数据立刻浮现：【金属含量87%...氧化程度推算距今约3200±200年】。更奇怪的是，分析显示墙壁内部嵌有规律的晶体结构，形成一张覆盖整个通道的能量网络。

"三千年前..."李元喃喃自语，"那不正是天元子封印九幽魔尊的时代吗？"

通道突然向下倾斜，坡度越来越陡。两人不得不扶着墙壁缓慢下行，掌心触及的金属壁面冰凉得不似寻常矿物。白子游突然停下，从药囊取出一小瓶荧光粉末撒向前方。粉末在空中形成发光的雾团，照亮了前方惊人的景象——

通道尽头是一个巨大的球形空间，直径至少百米。穹顶上镶嵌着无数发光的晶体，排列成星空图案。而最令人震惊的是，整个球形空间的墙壁上刻满了壁画，从入口处一直延伸到他们视线所及的最远处。

"这是..."白子游的声音因震惊而颤抖。

李元的系统突然自动激活扫描功能，将壁画内容转化为数据流输入他的意识。刹那间，他仿佛置身于三千年前的场景：一群穿着奇异服饰的人站在高科技设备前操作，其中两人格外醒目——一个戴眼镜的文雅男子和一个眼神阴鸷的瘦高个，正是天元子和裘幽的年轻模样！

壁画以连环画的形式展现了完整故事：天元子与裘幽来自异界（画面显示一个蓝色星球），因实验事故穿越到修仙世界。他们最初想用科技手段回家，却意外发现了九幽魔气的存在。裘幽被魔气侵蚀后叛变，天元子则创造了"系统"作为封印钥匙...

"李元！"白子游的呼唤将他拉回现实，"你看这段！"

最后几幅壁画显示天元子并非孤军奋战——有七位本土修士协助他，每人手持一件特殊法器。李元呼吸一滞：其中那位女修手中的剑，分明就是刘清音的玄天剑原型！而更令人毛骨悚然的是，裘幽身旁站着的黑袍人，腰间挂着一块与司空晦一模一样的紫金令牌！

"三千年前的轮回..."李元感到一阵眩晕。突然，系统强制弹出一条任务：

【立即前往控制中心】
【坐标：正下方50米】
【警告：能源即将耗尽】

与此同时，白子游发现壁画某处有个手掌大小的凹槽，形状与他的天机盘碎片完美契合。他犹豫地看向李元："要试试吗？"

李元刚要回答，通道上方突然传来岩石崩裂的巨响——追兵找到了入口！时间紧迫，他咬牙点头。白子游将青铜罗盘放入凹槽，严丝合缝。

刹那间，整个球形空间亮如白昼。穹顶的"星辰"开始移动，在中央汇聚成一幅三维星图。地面震颤着裂开，露出一个向下的金属阶梯。但最惊人的是，壁画中的人物突然"活"了过来，以全息影像的形式重现当年的对话：

"沈师兄，监控模块已经被裘幽篡改。"那位酷似刘清音的女修急切地说，"所有通过系统传输的数据都会被他截获！"

天元子——沈柯寒推了推眼镜："玉衡，启动隔离协议。把核心程序转移到..."他的声音突然变得模糊，影像开始闪烁。

白子游突然抓住李元的手臂："你听！"

上方通道中，密集的脚步声和金属碰撞声越来越近。更可怕的是，其中夹杂着非人的嘶吼——那些追兵已经完全魔化了！

"下去！"李元当机立断。两人刚踏上金属阶梯，头顶的入口就自动闭合，将追兵的咆哮隔绝在外。

阶梯呈螺旋状向下延伸，周围的墙壁上布满了精密的光路。李元注意到这些光路的排布方式与系统内部的能量轨迹惊人相似。随着深入，空气变得越来越冷，呼出的白气在面前凝结。

"这地方..."白子游的牙齿开始打颤，"简直像巨人的冰窖。"

终于，阶梯尽头出现一扇刻满符文的金属门。门中央有个圆盘，上面七个凹槽呈北斗七星排列。李元瞬间明白了什么，取出刘清音给的剑魄玉符，将其嵌入"天权"位的凹槽。玉符中的剑气自动激活，点亮了第一条光路。

"需要七把'钥匙'..."李元皱眉，"但我们只有一把。"

白子游却若有所思地取出三根银针，刺入自己脖颈穴位。随着一声闷哼，他的瞳孔突然变成淡金色："药王谷秘传的'开天眼'，可以暂时提升感知力。"他指向圆盘，"看能量流动...其实只需要激活天枢、天璇和摇光三个节点就能形成通路。"

李元将信将疑地按照他的指示，用系统能量模拟剑气注入另外两个凹槽。果然，圆盘开始旋转，金属门缓缓滑开。一股刺骨的寒气扑面而来，两人不由自主地后退半步——

门后是一个半球形密室，中央悬浮着一具水晶棺。棺中躺着一位白衣女子，面容安详如沉睡。当看清她的相貌时，李元如遭雷击：那分明是刘清音！或者说，是一个与刘清音长得一模一样的人！

"这不可能..."白子游震惊地喃喃，"看服饰风格，至少是三千年前的古人..."

李元走近水晶棺，系统突然不受控制地激活扫描功能。数据如洪水般涌入他的脑海：【生命体征：休眠状态...DNA匹配度：99.2%...灵魂波长：分裂体】。最后一项让李元浑身发冷——刘清音是这个古人的灵魂分裂体？

就在这时，水晶棺突然发出"咔嗒"轻响，棺盖缓缓滑开。一股淡蓝色雾气涌出，在空中凝结成一行文字：

「后继者，证明你的资格」

李元还没反应过来，地面突然塌陷！他整个人坠入黑暗，白子游的惊呼声迅速远去。下落过程持续了足足三秒，最后他重重摔在一片柔软的物质上。

【应急缓冲系统启动】
【检测到独立空间】
【警告：系统信号被屏蔽】

李元挣扎着爬起来，发现自己在一个狭小的六边形房间内。墙壁是半透明的，隐约可见外面流动的数据流。突然，对面墙壁亮起，显示出一段影像：

那是刘清音！她正在某个石室中与几位剑宗长老对峙，玄天剑已经折断，嘴角挂着血迹。影像没有声音，但能看到她愤怒地说着什么，而长老们则冷笑着举起武器...

"清音！"李元扑向墙壁，却穿了过去——那只是全息投影。紧接着，系统强制弹出一条消息：

【选择：立即前往救援或继续任务】
【注意：选择不可逆】

李元的手指悬在空中，内心天人交战。就在这时，房间突然响起一个机械化的声音："测试项目：情感优先级评估。请在三秒内做出选择。"

三...二...一...

李元咬牙选择了"继续任务"。影像立刻消失，墙壁上浮现一行新的文字：「理性高于情感，符合第一准则。准入许可授予。」

地面再次移动，将李元送入一个更大的空间。这里堆满了古老的电子设备，中央控制台上悬浮着一个蓝色立方体，正是放大版的系统核心！控制台前的全息屏幕显示着一行闪烁的警告：

【主程序已被污染】
【备用协议激活失败】
【最终防御机制剩余能量：3%】

李元突然明白了什么，冲向控制台。当他的手触碰到蓝色立方体时，整个房间亮起刺目的光芒。一段被尘封的记忆强行涌入他的意识——

那是天元子最后的时刻。他并非如传说中那样与九幽魔尊同归于尽，而是将自己转化成了系统最初的载体！而所谓的"回归协议"，实际上是一个精心设计的陷阱，目的是引诱九幽魔尊暴露其核心位置...

记忆突然中断，一个虚弱但清晰的声音直接在李元脑海中响起："终于等到你了，后继者。我是沈柯寒留在这里的AI副本。"

"天元子前辈！"李元又惊又喜，"到底发生了什么？为什么刘清音会..."

"时间不多了。"AI打断他，"主程序已被九幽渗透，它给你的所有任务都是陷阱。真正的第三块核心碎片在..."

一声巨响从上方传来，整个密室剧烈摇晃。AI的声音变得断断续续："白子游...危险...他体内的..."

天花板突然破裂，白子游浑身是血地跌落下来。他身后，三个紫眸黑袍人正从裂缝中爬出，嘴角咧开到不可思议的弧度，露出狰狞的笑容。

"李元...跑..."白子游挣扎着举起玉箫，却喷出一口黑血，"他们不是...人类..."

AI发出最后的警告："记住，系统可以重置，但代价是..."话音未落，一道紫光击穿了蓝色立方体，整个控制室陷入黑暗。

在最后的微光中，李元看到白子游腰间的药囊裂开，那块青铜罗盘碎片正发出诡异的紫光。而更可怕的是，碎片上浮现的数字编号此刻清晰可见——「07」。
