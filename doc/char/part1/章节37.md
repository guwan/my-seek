# 第三十七章 商队阴谋

沙漠边缘的绿洲在正午阳光下泛着粼粼波光。李元将昏迷的白子游安置在一棵棕榈树的阴影下，取出04号系统碎片再次检查他的伤势。碎片散发出的蓝光显示，白子游体内的07号子系统污染虽已清除，但焚血丹的反噬仍在蚕食他的生机。

"坚持住..."李元从系统商城中兑换出最后一支肾上腺素，注入白子游颈部，"再撑半天，我们就能到药王谷分舵了。"

白子游的眼皮颤动几下，却没有醒来。李元抬头望向远处起伏的沙丘，系统地图显示药王谷秘密分舵就在三十里外的一座孤山下。但更令他在意的是，沙漠中正有一支商队朝绿洲方向行进——这已经是今天遇到的第三支商队了。

"太频繁了..."李元眯起眼睛，启动系统远视功能。商队约二十人，骆驼上驮着标有药王谷标记的货箱，看似寻常。但当镜头拉近，他注意到每个商队成员的右手小指都戴着一枚紫铜指环——与司空家密探尸体上发现的一模一样！

"果然有诈。"李元迅速熄灭篝火，背起白子游准备撤离。就在这时，白子游突然抓住他的手腕，眼睛仍未睁开，嘴唇却微微翕动："别走...将计就计..."

李元一愣："你醒了？"

白子游的指尖在他掌心划出几个字：「商队有我要的东西」。

远处传来驼铃声，商队已经不足二里。李元权衡片刻，终于点头。他将04号碎片藏入鞋底，又用沙子掩盖了所有生活痕迹，然后故意在显眼处留下一块染血的布条。

商队很快发现了他们。为首的虬髯大汉跳下骆驼，假装关切地跑来："这位道友需要帮助吗？"

李元装作虚弱不堪的样子："我朋友...中毒了...求些解药..."

虬髯大汉眼中闪过一丝不易察觉的喜色，转身喊道："快拿'清灵散'来！"他蹲下身检查白子游，突然"惊讶"地瞪大眼睛："这不是白少主吗？"

李元心中一凛——对方果然认识白子游！他继续演戏："你们是...？"

"药王谷西域商队啊！"虬髯大汉热情地拍着胸脯，"白少主半年前还视察过我们分舵呢！"他朝手下使了个眼色，"快备担架，送两位回分舵医治！"

李元注意到那些"商队成员"行动过于训练有素，抬担架的手法更像是抬伤员的老兵。更可疑的是，其中一人偷偷将某种粉末撒在了白子游衣领上——系统检测显示那是追踪用的"千里香"。

商队转向东北方，那里根本不是地图上标记的分舵方向。李元假装不知情，一路上不断道谢。虬髯大汉自称姓吴，滔滔不绝地讲着药王谷的生意经，却几次说错基本的药材特性。

傍晚时分，商队抵达一处砂岩峡谷。谷口站着几名守卫，看到担架上的白子游后，立刻打开隐蔽的栅门。李元被"请"进一个灯火通明的大帐，帐内陈设华丽，正中坐着一位锦衣老者。

"久仰李道友大名。"老者笑吟吟地起身，"老朽乃药王谷西域执事周穆，多谢你救回我家少主。"

李元表面行礼，系统却在疯狂报警：【目标灵力波动与司空家修士相似度91%...检测到伪装法术痕迹...】。更令他心惊的是，扫描显示帐外埋伏着至少三十名修士，所有人小指上都戴着紫铜指环！

"周执事客气了。"李元故作轻松，"不知白兄何时能醒？"

"快了快了。"周穆拍拍手，侍女端上茶点，"少主只是中了些沙毒，服下特制解药就好。"他推过一杯香气扑鼻的茶，"李道友也请用些茶点，稍后谷主会亲自来道谢。"

茶中明显下了药，但系统分析显示只是普通迷药。李元假装饮用，实则将茶倒入袖中暗袋。不一会儿，他"昏昏沉沉"地趴倒在桌上。

帐内立刻安静下来。周穆的声音变得冰冷："检查那个天外来客，谷主要他的'系统'。"

有人翻动李元的衣物，当然一无所获。周穆咒骂一声："先把他们关起来，等子时仪式准备完毕再..."

李元被抬进一个阴暗的地牢，与白子游扔在一起。铁门关闭后，白子游立刻睁开眼，目光清明哪有半分昏迷的样子？

"演得不错。"他在李元手心写道，"我醒来后就感应到这里的'那个东西'了。"

李元挑眉："什么东西值得你冒险？"

白子游从口中吐出一粒米大小的玉珠，捏碎后露出里面的微型地图："药王谷至宝'神农鼎'的碎片，能解我体内焚血丹的毒素。"他指向地图某处，"就在这地牢正下方。"

"所以你早就知道这里是陷阱？"

"不全知道。"白子游苦笑，"三个月前父亲派我来西域调查弟子失踪案，临行前给了我这枚玉珠，说危急时刻能救命。现在看来..."他的声音低下去，"他可能早就被控制了。"

地牢突然震动，远处传来某种野兽的嘶吼。白子游脸色骤变："他们在唤醒'地龙'！那是药王谷镇压在禁地的凶兽，必须用活人献祭！"

李元启动系统扫描，地下结构图显示地牢下方确实有个巨大空洞，里面盘踞着一条似蛇非蛇的生物。而更深处，还有一个被重重封印的石室——想必就是存放神农鼎碎片的地方。

"计划很简单。"李元从鞋底取出04号碎片，"我制造混乱，你去找解药。然后..."

他的话戛然而止，因为系统突然检测到地面上有新的灵力波动——一个熟悉的气息正在快速接近！

"是清音！"李元又惊又喜，"她怎么找到这里的？"

白子游却神色凝重："不对...太巧了..."他摸索着从衣领夹层取出一片水晶，"看这个。"

水晶中显示出一段记忆画面：司空晦正在向部下展示刘清音的画像，下令要活捉她。"她的魂魄是唤醒魔尊的关键。"司空晦的声音在画面中回荡，"玉衡转世必须完整。"

地牢外突然响起打斗声，接着是守卫的惨叫。白子游急忙收起水晶："无论来的是真是假，先按原计划行事！"

铁门被一道剑气劈开，烟尘中浮现出刘清音的身影。她手中的冰魄剑灵熠熠生辉，身后倒着十几名守卫。

"李元！"她冲上前，"我通过同心印感应到你有危险！"

李元刚要回应，系统突然弹出鲜红警告：【检测到异常灵魂波动...目标DNA匹配但灵纹不符...】。他心头一震——这不是真正的刘清音！

假刘清音已经近在咫尺，冰魄剑直刺他心口。千钧一发之际，白子游抛出一把粉末，逼得对方后退半步。李元趁机激活04号碎片，一道蓝光击中"刘清音"面部，伪装法术顿时崩溃——露出周穆那张老脸！

"老东西演技不错嘛。"李元冷笑。

周穆见计败露，猛地扯下胸前玉佩摔碎。地牢剧烈震动，地下传来岩石崩裂的巨响！

"地龙醒了！"白子游大喊，"它被释放出来了！"

周穆狂笑着后退："你们就等着成为祭品吧！"他突然表情扭曲，七窍中涌出黑血——有人远程激活了他体内的禁制！

地牢开始坍塌，李元拉起白子游冲向通道。身后，地面轰然裂开，一条足有水桶粗的黑色巨物破土而出。那生物形似蜈蚣，每一节甲壳上都长着人脸图案，正是药王谷古籍记载的凶兽"百面地龙"！

"分头行动！"李元将04号碎片塞给白子游，"你去拿解药，我引开这怪物！"

白子游还想说什么，李元已经冲向相反方向，朝地龙扔出一把飞刀。凶兽果然被激怒，扭动着庞大的身躯追去。

通道错综复杂，李元不断制造声响引导地龙深入地下。通过系统扫描，他发现凶兽腹部有块异样的白斑——那正是药王谷历代谷主控制地龙的"命门"！

"系统，计算最佳攻击路线！"

【计算完成...建议使用电磁脉冲干扰其神经节...成功率67%...】

李元边跑边从商城中兑换出几块磁石，用衣带捆成简易电磁装置。当地龙追至一处狭窄弯道时，他猛地转身，将装置拍在墙上激活！

刺耳的尖啸声中，地龙痛苦地翻滚起来。李元抓住机会，纵身跃上其背部，徒手撕开那块白斑处的甲壳。里面果然嵌着一块控制玉牌，他毫不犹豫地将其捏碎。

地龙顿时僵直，随后所有足肢同时收缩，变成一个巨大的黑球滚入深渊。李元气喘吁吁地靠在墙上，这才发现误打误撞来到了封印石室门前！

石门上的禁制已被地龙破坏，室内中央的石台上，静静漂浮着一块青铜碎片——正是神农鼎的一部分。而更令李元震惊的是，碎片旁边还放着一块蓝色晶体，上面清晰标着"05"！

"第五块系统碎片？！"他刚要上前，身后传来脚步声。白子游满身是血地冲进来，手中握着04号碎片和几株奇异的草药。

"得手了！"白子游欣喜道，随即看到05号碎片，脸色骤变，"等等，别碰它！那是——"

话未说完，05号碎片突然自动飞起，与李元手中的04号碎片产生强烈共鸣。两片晶体在空中旋转，释放出的能量波将整个石室照得如同白昼。一段全息影像自动播放：

那是天元子——沈柯寒的临终画面。他虚弱地躺在玉台上，对身旁的"刘清音"（玉衡）说："...系统被裘幽污染了核心协议...必须找到所有碎片...重组..."

影像突然中断，05号碎片"咔嗒"一声与04号完美拼接，形成一个更大的晶体。系统界面随之刷新：

【系统完整度：65%】
【新功能解锁：灵魂扫描】
【警告：检测到主程序异常...】

李元还来不及细看，整个地下空间突然剧烈震动！石块如雨般落下，通道接连坍塌。

"上面打起来了！"白子游拉着李元往外跑，"我上来时看到真的刘清音在和司空家修士交手！"

两人在崩塌的通道中拼命奔逃，终于从一个裂缝爬回地面。眼前的场景令人窒息——整个营地已成废墟，天空中两道身影正在激战：一边是手持冰魄剑的刘清音，另一边则是...另一个刘清音？

"什么情况？"李元瞠目结舌。

白子游吞下刚找到的解药，脸色好了许多："那是玉衡长老的残魂显化！她感应到剑灵危机，从剑宗禁地赶来了！"

两个"刘清音"虽然长相一模一样，但招式截然不同。一个剑气如冰，一个剑势如火。她们背靠背作战，周围倒着数十名黑袍修士的尸首。

李元刚要上前助阵，系统突然强制弹出一条消息：

【终极任务更新：收集所有碎片（5/7）】
【下一目标：南海归墟】
【备注：月圆之夜前必须完成】

与此同时，他怀中的合并碎片突然发烫，投射出一幅地图：南海某处标记着红点，旁边标注着「06号碎片坐标」。而更下方还有一行小字：「最终碎片在...」，后面的内容被故意抹去了。

战斗接近尾声，最后一个黑袍修士被冰火剑气绞碎。两个"刘清音"缓缓落地，彼此对视一眼后，较年长的那位开始变得透明。

"时间到了。"她温柔地对年轻的刘清音说，"记住，你我本是一体。"又看向李元，"天外来客，保护好她..."

残魂消散前，弹出一道金光没入李元眉心。他顿时感到系统能量暴涨，界面上的完整度跳到了70%！

刘清音收回冰魄剑，疲惫地走向李元："总算找到你了。"她的目光落在白子游身上，微微皱眉，"他是...？"

"说来话长。"李元握住她的手，通过同心印瞬间分享了所有经历。刘清音的脸色越来越凝重，尤其是看到司空晦利用林小凡传话的部分。

"月圆之夜...就是后天了。"她沉声道，"我们必须在此之前赶到葬神坑。"

白子游服下解药后气色好转，正收拾散落的药囊。突然，他从一名黑袍修士的储物袋中摸出一卷画像，展开后倒吸一口冷气："你们看这个！"

画像上是刘清音的全身像，但最诡异的是，她心口位置被朱砂画了一个靶心标记，旁边写着「容器候选：甲等」。

"容器..."李元想起水晶中的记忆画面，"司空晦到底想用你做什么？"

刘清音沉默片刻，冰魄剑灵突然开口："他想复活九幽魔尊，需要玉衡转世的身体作为容器。"剑灵的光芒暗淡下来，"而更可怕的是...这个计划可能从一开始就..."

话未说完，远处天空突然乌云密布，一道血色光柱从云层直射而下。光柱中隐约可见一座山峰的轮廓——正是葬神坑所在的位置！

"开始了..."白子游声音发抖，"月圆之夜的仪式提前了！"

三人对视一眼，不约而同地朝光柱方向奔去。李元不知道的是，在他系统深处，随着碎片合并，一段被标记为【主程序】的代码正在悄然改变着最终任务的参数...
