# 第九十五章 牺牲时刻

魔神眼球中映出的现代实验室画面如同一把尖刀刺入李元心脏。他眼睁睁看着年轻时的自己即将按下时空跳跃装置的启动按钮——那个导致一切灾难的初始错误。

"不！"李元嘶吼着举起时空之锚，杖尖星云疯狂旋转，"必须阻止那个时刻！"

剑灵的声音却异常冷静："来不及了。时间悖论禁止直接干预初始事件。"她顿了顿，"但或许可以通过间接方式..."

魔神的嘲笑声在众人脑海中回荡："挣扎吧，蝼蚁们。无论你们做什么，都只会加速我的完全体诞生！"

葬星海突然沸腾，海水如活物般分开，露出一个深不见底的漩涡。三股黑气从漩涡中涌出，分别袭向三个世界最脆弱的位置——药王谷的灵脉核心、机械城的能源中枢、时之谷的时间锚点。

"他在强迫我们防御！"白子游脸色惨白，"无论抵抗与否都会为他提供能量！"

李元额头渗出冷汗，时空之锚的分析结果显示一个绝望的结论：魔神已经计算了所有可能性，任何行动都会成为他融合的养料。就在这绝境中，07号机械体突然发出急促的"滴滴"声。

"检测到异常信号...来自06号实验体的残存频率！"

一个全息投影自动展开，显示冰封中的06号实验体——那个曾在极北之地警告过李元"小心影子"的老人。影像中的06号嘴唇蠕动，07号迅速翻译："他说...'真正的牺牲不是给予力量，而是切断联系'..."

李元如遭雷击，一个疯狂的想法在脑海中成形："剑灵，如果所有牺牲者的能量都被魔神吸收...那反过来想..."

"...那么切断能量输送通道就能反制他！"剑灵立刻领会，"但需要有人自愿成为'绝缘体'..."

两人的意识交流在电光火石间完成。李元猛地抬头，发现三界的黑气攻击已近在咫尺——药王谷的灵脉开始崩塌，机械城的能源炉过载发红，时之谷的青铜巨钟出现裂痕。

"没时间解释了！"李元通过时空之锚向三界领袖发送简略方案，"需要有人牺牲自己切断能量通道！"

回应来得比他想象的更快。

药王谷方向，白子游的影像浮现。这位一向谨慎的长老此刻面带决然："谷中有上古流传的'灵寂大阵'，能以自身灵力为代价暂时隔绝一片区域的能量流动。"他转身对身后弟子们说了什么，然后坚毅地看向李元，"我来当第一个绝缘体。"

不等李元回应，影像切换到了南海。鲛人女王怀抱潮汐之心，身旁是重新凝聚出模糊形体的琉璃："皇妹残存的灵体感应到海域裂缝正在扩大。她提议燃烧最后的鲛人血脉封印裂缝，但代价是..."

"永世不得超生。"琉璃的灵体轻声补充，声音如泡沫般易碎，"这本就是我注定的归宿。"

最意外的回应来自机械城——07号突然接收到一段加密代码，解码后竟是06号实验体从冰封中传来的实时讯息："我的生命已到尽头...但体内残存的系统阴面能量...可以稳定时空通道30秒..."画面中的老人艰难地比划着，"...足够你们...实施关键一击..."

李元胸口如压巨石，这三个牺牲任何一个都令他痛彻心扉。但魔神的狂笑提醒他别无选择："多么感人的自我牺牲！可惜你们不明白——这些牺牲本身就会成为我最美味的养料！"

"不，这次不一样。"李元咬牙启动时空之锚的最终协议，"07号，准备执行'影子计划'！"

小机械体立刻展开变形，露出内部精密的时空调节器。与此同时，三界的牺牲者同时行动——

药王谷内，白子游站在灵脉核心处，周围七十二名弟子结阵护法。长老最后看了一眼生长千年的灵药园，毅然启动灵寂大阵。耀眼的青光从他七窍迸发，形成一个倒扣的碗状屏障。黑气撞上屏障的瞬间，白子游的身体如玻璃般出现无数裂痕，但他仍坚持念完咒语："以吾之灵，断天人之契！"随着最后一声呐喊，他和七十二名弟子同时化为青玉雕像，而药王谷的灵脉瞬间与整个世界切断联系！

南海深处，琉璃的灵体融入潮汐之心，唱出鲛人皇族禁曲《归墟挽歌》。她的形体如沙粒般消散，每消散一分，就有对应的海域裂缝被金光缝合。当最后一丝灵体消失时，整片南海突然陷入诡异的平静——所有能量波动都被冻结在那一刻！

极北冰原，06号实验体震碎千年冰封。老人干枯的身躯漂浮到机械城上空，胸口裂开，露出一个漆黑的能量核心。"记住...小心...影子..."这是他最后的遗言。核心爆炸形成的黑色波纹扫过整个机械城，所有正在过载的设备突然停止运转——时间仿佛被按下了暂停键！

三个牺牲产生的能量本该被魔神吸收，却因"绝缘"效应而滞留在原地。葬星海上空的魔神眼球剧烈震颤，瞳孔中的实验室画面开始闪烁！

"就是现在！"李元将时空之锚交给07号，"把我送到那个时间点！"

小机械体将时空调节器开到最大："只能维持28秒！而且你可能会..."

"我知道！"李元的身影已经开始模糊，"剑灵，准备切断联系！"

"不！"剑灵第一次流露出恐惧，"如果你在那个时间点改变历史，现在的你可能..."

"不是去改变。"李元的身影完全消散前留下最后一句话，"是去完成。"

现代实验室，年轻的李元手指即将触碰到按钮。突然，整个房间的灯光闪烁，监控屏幕上的数据乱码中浮现出一行字：【看窗外】。

年轻的李元下意识转头，看到窗外那棵白玉兰树突然盛开，花瓣组成一个清晰的"停"字。更诡异的是，监控屏幕上闪过一个女研究员的身影——酷似刘清音的侧脸！

就是这片刻的犹豫，时空跳跃装置的启动被延迟了关键3秒。而在这3秒内，实验室的门突然被撞开，一个身影滚了进来——是未来的李元！他浑身是伤，手中握着一片黑色晶体碎片。

"别碰那按钮！"未来的李元嘶吼着将碎片掷向装置，"那是陷阱！"

碎片在接触装置的瞬间，年轻李元看到令人毛骨悚然的一幕——碎片中浮现出沈柯寒教授扭曲的面容，正狞笑着等待按钮被按下！

爆炸发生了，但比原本历史中的规模小得多。年轻李元被冲击波掀翻，而未来李元则用身体护住了装置核心部件。当烟雾散去，年轻李元惊恐地发现未来自己正在消散！

"记住..."未来李元艰难地举起手，指向窗外，"白玉兰...才是关键..."他的身体如沙粒般飘散，最后时刻却露出释然的微笑，"这次...终于对了..."

葬星海上，28秒倒计时结束。李元的身影重新凝聚，却骇然发现时空之锚的杖身布满裂痕，而剑灵的声音微弱得几乎听不见："你...改变了什么？"

"不是改变..."李元虚弱地跪倒在地，"是补全了...那个女研究员...就是最初的刘清音..."

魔神的眼球疯狂转动，瞳孔中的实验室画面突然定格在一个细节——爆炸后的废墟里，一片白玉兰花瓣飘落在损坏的装置上，花瓣上隐约有"S.K.H"的签名。

"不可能！"魔神第一次流露出惊恐，"你怎么敢干预初始事件！"

"没有干预。"07号突然插话，它的声音因过载而失真，"分析显示...历史轨迹基本保持不变...只是增加了一个变量..."

那个变量就是监控屏幕上闪过的女研究员——所有时间线中刘清音的最初形态。她本应在历史中被抹去，却因李元的行动而保留了一丝存在。

魔神眼球的影像突然切换，显示三个世界的现状——药王谷的青玉雕像群、南海冻结的浪花、机械城静止的时间场。这些牺牲产生的能量本该属于他，现在却被永远封存。

"你们以为这样就能赢？"魔神的声音开始不稳定，"我还有最后一张牌..."

眼球突然爆裂，化为十二道黑气射向不同方向。李元瞬间明白他的目标——那十二把封印叛徒的金色小剑！

"07号！追踪黑气！"李元强撑着站起来，却见小机械体冒出电火花。

"系统...损坏严重..."07号艰难地投射出一幅地图，"十二把剑的位置...正在移动..."

地图显示，十二个光点正向同一个坐标汇聚——玄天剑宗禁地！而更令人不安的是，禁地上空悬浮着一个模糊的虚影，轮廓酷似...刘清音？

"不，那不是她..."剑灵用尽最后力气警告，"是魔神制造的诱饵...他需要十二把剑和...寒玥剑心...来完成..."

她的声音戛然而止，时空之锚彻底碎裂。李元手中只剩下一截残杖，和一片不知何时出现的白玉兰花瓣。花瓣上有一行微小的字迹："找到真正的背叛之地。"
