# 第十七章 越狱计划

玄天剑宗的祖师祠堂在血色月光下显得格外阴森。李元和刘清音躲在祠堂外的古松后，看着巡逻弟子机械地来回走动——他们额头上的紫色印记比之前更加明显了。

"祠堂正门走不通，"刘清音压低声音，"但我知道侧殿有条密道。"

李元摸了摸怀中五块天元碎片，它们正发出异常的温热。"等等，"他突然拉住刘清音，"不对劲，这些巡逻弟子的路线太规律了，简直像..."

"像在等我们自投罗网。"刘清音接过话头，眉头紧锁。她突然注意到祠堂屋檐下悬挂的青铜铃铛——本该随风轻响的铃铛全都诡异地静止着。

李元从储物袋摸出一块肥皂——这是前几天在系统商城兑换的生活用品。他用青锋剑快速削出几个小巧的滑轮和钩子。"帮我盯着，"他低声道，双手灵巧地组装着简易滑锁工具，"三十秒就好。"

【限时任务触发：绝地逃脱】
【目标：在追兵发现前潜入祠堂密道】
【奖励：高级隐身符×3（持续时间15分钟）】

系统提示音刚落，远处突然传来刺耳的警报声。一队紫袍修士御剑而来，为首的正是执法堂副堂主赵寒，他手中拿着一个不断闪烁红光的罗盘。

"搜！"赵寒厉喝，"天元碎片的气息就在这附近！"

李元迅速将完成的滑锁工具卡在古松枝干上，另一端的钩子精准勾住了祠堂侧殿的窗棂。"抓紧我！"他搂住刘清音的腰，两人借着绳索的弹力悄无声息地滑向祠堂。

就在他们即将抵达窗边时，赵寒突然转头看向古松方向："谁在那里？！"一道剑光劈来，绳索应声而断！

"跳！"李元在坠落瞬间猛蹬墙壁，抱着刘清音撞破窗纸滚入祠堂。碎木屑划破了他的脸颊，但此刻顾不得疼痛——沉重的脚步声已经逼近窗口。

刘清音迅速掐诀，一道清风符将破碎的窗纸恢复如初。两人屏息贴在窗下，听着赵寒的脚步声在窗外徘徊。

"奇怪..."赵寒的声音近在咫尺，"罗盘显示就在这..."

"副堂主！"远处有人呼喊，"东南角发现可疑人影！"

脚步声渐渐远去，李元长舒一口气。这时系统奖励的三张隐身符飘然落入掌心，符纸上流转的银色纹路比普通隐身符复杂数倍。

祠堂内部比想象中宽敞，历代祖师的牌位在烛光下泛着幽光。最引人注目的是中央天元子的白玉雕像——与李元在秘境壁画上见到的形象一模一样，只是雕像手中的剑不见了，取而代之的是一块凹陷的印记。

"密道在祖师像后面。"刘清音轻声道，"但需要宗主令或者..."

李元突然掏出莫长老给的玉牌，上面的七星纹路正与雕像基座的凹槽吻合。当玉牌嵌入的瞬间，整座雕像缓缓平移，露出向下的阶梯。一股带着霉味的冷风从地道涌出，隐约夹杂着金属摩擦的声响。

两人激活隐身符，小心地步入地道。石阶湿滑阴冷，墙壁上每隔十步就嵌着一颗发光的幽蓝晶石。随着深入，李元发现这些晶石的排列方式似曾相识——与系统界面边缘的装饰纹路几乎一致。

地道尽头是一扇刻满符文的青铜门，门缝中透出诡异的绿光。李元正要上前查探，突然听到门内传来司空晦沙哑的声音：

"魔尊大人放心，血月之夜前必定集齐所有祭品。"

另一个声音让李元浑身血液几乎凝固——那声音像是千万人同时在低语，每个音节都让地道墙壁震颤："...第七块碎片...天外来客的身体...完美容器..."

刘清音的手猛地攥紧李元的衣袖，他能感觉到她在颤抖。透过门缝，他们看到司空晦跪在一个血色法阵中央，对面悬浮着一团不断扭曲的黑雾。更骇人的是，法阵四周躺着十几名昏迷的剑宗弟子，每个人的心口都连着一根血线，源源不断地向黑雾输送着某种能量。

"三日后血月当空，魔尊降临的通道就能完全稳定。"司空晦的声音充满狂热，"那个叫李元的小子体内系统，正是最佳的操控枢纽！"

黑雾发出令人毛骨悚然的笑声："...天元子当年封印我们...就用的是异界技术...如今他的传人亲手带来解封的钥匙...讽刺..."

李元如坠冰窟。他突然意识到，自己的穿越或许从来都不是意外，系统可能从一开始就是九幽布局的一部分！这个念头刚起，系统界面突然剧烈闪烁，弹出一条他从未见过的血色警告：

【核心协议触发：宿主认知偏差纠正】
【警告：禁止怀疑系统来源】
【强制镇静程序启动】

一股电流般的刺痛从脊椎窜上大脑，李元差点叫出声来。刘清音及时捂住他的嘴，拖着他退回转角。

"我们必须离开，"她贴着李元的耳朵说，声音轻得几乎听不见，"他们说的血月之夜就是护山大阵完全崩溃的时刻！"

就在这时，青铜门突然打开，司空晦迈步而出，距离隐身状态的二人仅三步之遥！他脖子上挂着一个骨制吊坠，吊坠里嵌着的正是第六块天元碎片。

"奇怪..."司空晦抽动鼻子，"怎么有天元碎片的气息？"他的目光如刀般扫过二人藏身的转角。

千钧一发之际，地道上方突然传来剧烈的爆炸声，整条地道都在震颤。司空晦咒骂一声，化作黑雾冲向地面。

"走！"李元拉着刘清音冲向另一条岔路——那里有微弱的气流流动，可能通向外界。

奔跑中，李元注意到系统界面仍闪烁着不稳定的红光。最下方有一行几乎透明的文字正在缓慢浮现：【回归协议...激活条件...集齐碎片...】但后面的内容被某种力量强行抹去了。

地道出口竟然设在剑宗后山的瀑布后方。两人冲出瀑布时，隐身符刚好失效。夜空中的血月已经比平时大了整整一圈，散发着不祥的红光。更可怕的是，剑宗上空的裂缝中，九幽魔尊的一只巨手已经完全伸出，正缓慢而坚定地撕扯着空间障壁。

"三天..."李元声音嘶哑，"我们只有三天时间找到最后一块碎片。"

刘清音突然指向主峰："看！"

星移大阵所在的主峰顶端，七根石柱中的五根已经亮起血色光芒。而最中央的石台上，一个熟悉的身影正在布置某种仪式——赫然是已经魔化的莫长老！

"我明白了，"李元握紧拳头，"第七块碎片就在星移大阵核心。他们要用七块碎片作为坐标，引导九幽魔尊完全降临！"

刘清音突然转身按住李元的肩膀："等等，司空晦说你的身体是什么...完美容器？这是什么意思？"

李元苦笑一声，正要回答，远处的树林突然惊起一片飞鸟。两人对视一眼，迅速躲入瀑布后的洞穴。这个偶然发现的避难所将成为他们最后计划的关键——而在洞穴深处的石壁上，刻着一幅让李元毛骨悚然的壁画：一个酷似他的现代装束青年，站在七色光柱中，身后是破碎的天空与狞笑的魔影。

壁画下方题着八个血字："天外来客，归途即末"。
