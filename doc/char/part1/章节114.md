# 第一百一十四章 转世重逢

敦煌的夜空繁星如洗，李元站在莫高窟景区外的小旅馆阳台上，手中握着那枚S.K.H-01芯片。芯片在月光下泛着微弱的蓝光，投射出一幅只有他能看到的微型星图——指向莫高窟第112窟的《反弹琵琶》壁画。

"刘清音，快来看这个。"他转头呼唤，却发现房间里空无一人。浴室水声停止，但走出来的不是刘清音，而是一个陌生女子——海蓝色长发，眼睛在黑暗中泛着珍珠般的光泽。

"李元师兄，好久不见。"女子微笑着，声音如同海浪轻抚沙滩，"我是琉..."

话音未落，她的形象闪烁了一下，又变回穿着浴袍的刘清音。她困惑地摸了摸自己的脸："刚才...我是不是又变身了？"

李元深吸一口气："是琉璃的记忆在与你融合。从我们拿到芯片开始，你的剑灵特质就在增强。"他指向芯片投影，"看，星图显示下一枚芯片藏在《反弹琵琶》壁画里，但..."

"但那里现在不对外开放。"刘清音接话，眼睛突然变成淡蓝色，"不过我知道一条密道。前世...不，琉璃的记忆里有。"

李元若有所思地看着她："你确定要这么做吗？每次前世记忆浮现，你作为'刘清音'的人格就会..."

"变淡？"刘清音苦笑，举起右手腕，剑痕胎记已经蔓延成鳞片状花纹，"我觉得已经停不下来了。昨晚我梦见自己沉在海底三千年，醒来时枕头都是湿的。"

窗外突然传来缥缈的歌声，旋律古老而忧伤，正是《归墟挽歌》。两人同时一震，冲到窗前。对面酒吧的露天舞台上，一位身着蓝裙的女歌手正在演唱，她的手腕在聚光灯下隐约可见鳞片状的反光。

"琉璃的转世！"刘清音脱口而出，眼中蓝光大盛，"她在用歌声召唤同类！"

两人匆忙下楼，挤进酒吧人群。近距离看，女歌手约二十出头，左腕确实有一圈鲛人鳞片形状的胎记。更神奇的是，每当她唱到高音部分，空气中就会浮现出肉眼几乎不可察的蓝色光点，落在听众身上，有人开始莫名流泪，有人则露出顿悟的表情。

"她在唤醒前世记忆..."李元低声道，突然注意到角落里一个穿灰西装的男人正用手机拍摄歌手，眼神狂热而不自然。当歌手换到一首更古老的曲子时，灰西装男子突然捂住耳朵，表情痛苦地冲出酒吧。

"追！"李元示意刘清音留下保护歌手，自己跟了出去。

巷道里，灰西装男子边跑边撕扯自己的衣服，露出胸口一个狰狞的魔纹——正是司空晦的标志！男子跪倒在地，发出非人的咆哮："滚出...我的脑子！"这声音一半是他自己的，另一半却是李元熟悉的魔神语调。

李元正犹豫是否上前，男子突然安静下来，整了整衣领站起身，眼神完全变了："李元，好久不见。"声音已是纯粹的魔神腔调，"没想到你们先找到了歌者。不过没关系，她很快就会加入我的...合唱团。"

"你休想。"李元悄悄激活手中的芯片，"这次你连古董都没得附身了。"

灰西装男子——或者说魔神——露出诡异的微笑："谁说我要附身了？"他突然扯开衬衫，胸口魔纹组成一个逆向的世界树图案，"这个世界的人类天生就是最好的容器，特别是...那些转世者。"

话音未落，他的身体突然分解成无数黑雾粒子，消散在夜风中。李元立刻意识到中计了，转身冲回酒吧，却看到更惊人的一幕：

刘清音站在舞台上，与蓝裙歌手十指相扣，两人被一个水泡般的蓝色光球笼罩。观众们如痴如醉地仰望，每个人眼中都闪烁着记忆的蓝光。更可怕的是，酒吧的每个阴影处都站着灰西装男子——足足有二十多个完全相同的复制体！

"群体附身..."李元倒吸一口冷气。魔神这次不是占据一个宿主，而是分散成了无数碎片！

就在复制体们同时向舞台逼近时，蓝裙歌手突然飙出一个高音，声波具象化成无数蓝色光刃，将最近的五个灰西装男子钉在墙上。刘清音则右手一挥，剑痕胎记延伸出一道金光长剑，摆出玄天剑宗的起手式。

"李元！芯片！"她大喊。

李元会意，将S.K.H-01芯片高高抛向舞台。芯片穿过蓝色光罩的瞬间，歌手脖子上的贝壳项链突然打开，露出里面隐藏的S.K.H-02芯片！两枚芯片在空中相撞，爆发出耀眼的金蓝色十字光芒。

所有灰西装复制体同时惨叫，胸口魔纹如烧焦的纸片般剥落。观众们如梦初醒，困惑地互相张望。光芒散去后，舞台上只剩下刘清音一人，蓝裙歌手和两枚芯片都不见了。

"她去了安全的地方。"刘清音走到李元身边，递给他一张贝壳形状的便签，"临走前给了我这个。"

便签上用荧光墨水写着："第三枚芯片在西湖底雷峰塔地宫，但别急着去——先找到转世的白子游，只有他能解读芯片密码。小心穿红鞋的观察者。"

李元皱眉："红鞋的观察者？什么意思？"

刘清音突然身体一晃，大量不属于她的记忆涌现：一个穿红鞋的小女孩站在世界树下记录数据、七个戴着红宝石戒指的科学家在秘密会议、以及...沈柯寒教授将一枚红水晶芯片植入某个实验体后脑的场景。

"不是红鞋..."她脸色苍白地纠正，"是红石！S.K.H系列芯片的监控模块！有人在用红石芯片监视所有转世者！"

仿佛印证她的话，酒吧角落里，一个不起眼的服务生悄悄退入阴影。他转身的瞬间，后颈隐约闪过红光的"07"字样。
