# 第十六章 长老审讯

星移大阵上空的裂缝如同狰狞的伤口撕裂天际，李元和刘清音却在距离阵眼百米处被一道金光屏障拦截。十二名执法堂弟子从四面八方涌出，为首的灰袍老者手持禁灵锁，须发皆张。

"叛徒刘清音！"莫长老声如洪钟，禁灵锁化作金光直取刘清音手腕，"还有这个来历不明的贼子！"

刘清音旋身避开，玄天剑在空中划出银色弧光："莫长老且慢！我们是为阻止九幽——"

"住口！"莫长老袖中飞出七张符箓，在空中结成北斗困阵，"护山大阵崩溃在即，你们却盗取剑冢至宝！"他目光扫过李元怀中的天元碎片，瞳孔骤缩，"果然是天元碎片！"

李元突然发现系统界面变成危险的红色。他急忙按住刘清音持剑的手，低声道："不能硬拼，先跟他们走。"

在莫长老押解下穿过剑宗主殿时，李元注意到沿途建筑都笼罩着诡异的黑雾。几个被控制的弟子机械地搬运着刻有符文的黑石，当他们经过时，那些弟子突然齐刷刷转头——额头上全都有相同的紫色印记。

囚室设在执法堂地底，玄铁打造的栅栏上流动着封印符文。当禁灵锁扣上手腕时，李元发现系统能量正在被缓慢抽取。

"说！"莫长老一掌拍在石桌上，化神威压让空气都变得粘稠，"你们与司空晦是什么关系？为何要破坏护山大阵？"

刘清音突然咬破指尖，在眉心画出血符："弟子以道心起誓，若所言有虚，愿受心魔反噬而亡！"她一字一顿说出秘境见闻和司空晦的阴谋，当说到"九幽魔尊"时，囚室内的烛火突然全部变成诡异的绿色。

莫长老脸色阴晴不定，正要开口，石门突然被推开。一个执法弟子慌张跑来："长老，正道盟司空长老到访，说是...来捉拿奸细。"

司空晦踏入囚室时，李元立刻感受到系统剧烈的能量波动。现在的司空晦比秘境所见更加非人化——左脸爬满鳞片，脖颈处隐约可见蠕动的血管。

"莫道友好久不见。"司空晦的声音像两把生锈的刀在摩擦，目光扫过李元时闪过一丝贪婪，"这两个小贼盗取我正道盟机密，还请移交处理。"

刘清音突然冷笑："司空长老好手段，先用黑石污染护山大阵，再嫁祸于人。"她猛地扯开衣领，露出锁骨处发光的剑形印记，"玄天剑认主为证，孰是孰非自有公断！"

司空晦眼中凶光暴涨，袖中黑气刚要涌出，莫长老却突然横跨一步挡在中间："司空道友，此女既持玄天剑，按律当由宗主发落。"

两人目光相接的刹那，李元清晰地看到莫长老腰间玉佩亮起微光。司空晦突然收敛杀气，意味深长地笑道："那便三日后公审。只是..."他指尖弹出一缕黑气没入李元体内，"这小贼身上的九幽气息，莫道友可要看紧了。"

黑气入体的瞬间，李元眼前闪过无数破碎画面——九幽魔尊的咆哮、系统创造者的背影、以及...天元子手持七块碎片站在星移大阵中央的场景。系统疯狂弹出警告，却在黑气侵蚀下逐渐模糊。

待司空晦离去，莫长老突然掐诀布下隔音结界。他颤抖着从怀中取出一枚玉简："清音师侄，林肃师兄临终前...可有什么交代？"

刘清音警惕地盯着他："长老为何突然..."

"没时间了！"莫长老急得额头冒汗，"护山大阵最多再撑十二个时辰，若你们真有碎片..."他话未说完，突然喷出一口黑血，脖颈处浮现与司空晦如出一辙的紫色纹路。

"原来如此..."李元恍然大悟，"莫长老也被控制了，但还在抵抗！"他挣扎着从怀中掏出天元碎片，碎片感应到黑气，立刻发出耀眼的蓝光。

莫长老在光芒中痛苦蜷缩，却咬牙坚持："后山...祖师祠堂...有密道..."他猛地推开二人，"走！趁我还能...控制..."

牢门突然被撞开，三名双眼泛着紫光的执法弟子持剑冲入。刘清音玄天剑出鞘，剑光如银河倾泻，却在触及敌人前被一道黑影拦截——司空晦不知何时已返回，正阴笑着站在囚室中央。

"精彩的抵抗。"他抬手间黑气化作锁链缠住刘清音，"可惜..."话音未落，整座执法堂突然剧烈震动，远处传来惊天动地的爆炸声。

司空晦脸色骤变："星移大阵？！"他顾不得二人，化作黑雾冲向声源处。

李元趁机用碎片划破禁灵锁，拉起刘清音就往外冲。经过莫长老身边时，老人用最后力气塞给他们一块玉牌："祠堂...七星...排列..."随即彻底被黑气吞噬。

两人在混乱中逃出执法堂，只见主峰方向紫光冲天，空间裂缝已扩张到覆盖半个天空。无数黑影正从裂缝中涌出，最庞大的那个轮廓——九幽魔尊的头颅已经探出大半！

"去祖师祠堂！"李元握紧玉牌，上面刻着的七星图案正与天元碎片产生共鸣，"莫长老用命换来的线索，绝不能浪费！"

刘清音却突然拉住他："等等...执法长老与司空晦交换的眼神，你不觉得奇怪吗？"她声音发颤，"如果整个剑宗高层都..."

李元心头一震，系统此刻突然恢复部分功能，跳出一条被加密的信息：【检测到同源控制信号】【来源：剑宗地脉核心】。他望向远处扭曲的天空，一个可怕的猜想逐渐成形——或许司空晦从来都不是主谋，而是被更古老的存在操控的棋子。

祖师祠堂的飞檐已在视野中浮现，而身后的追兵脚步声也越来越近。李元将五块碎片拼在一起，地图上代表剑宗的位置正闪烁着刺目的红光。无论等待他们的是真相还是陷阱，这场生死竞速都已无法回头。
