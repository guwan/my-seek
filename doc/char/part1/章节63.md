# 第六十三章 记忆迷宫

琉璃的手收回空间裂缝的刹那，李元纵身扑去，却只抓住一缕消散的紫雾。00号晶体在她指尖闪烁着妖异光芒，映照出那张熟悉又陌生的脸——琉璃的瞳孔已变成竖瞳，额头的金纹转为深紫。

"为什么？"李元的声音嘶哑得不像自己。

琉璃——或者说占据她身体的00号——歪头露出孩童般的笑容："哥哥，你忘了吗？是你亲手把我封印在系统深处的。"她轻抚胸口，"多亏07号帮忙，我才能借用鲛人公主的躯壳。"

寒玥-凌霜的剑光突然袭来！00号随手一挥，剑气便在空中凝固。"别急嘛，剑灵姐姐。"她调皮地眨眨眼，"好戏才刚开始呢。"

金色大网外的司空晦完全体突然发出震天咆哮，整个剑宗地界剧烈震动！血色光柱中浮现出十二个扭曲人影——正是被污染的十二实验体虚影。

"三天？"00号咯咯笑着，"你们连三刻钟都撑不住哦~"她突然将00号晶体按入自己眉心，"来看看真正的历史吧！"

紫光爆闪，李元感到意识被强行抽离。再睁眼时，已站在一座古老的祭坛上，四周是无边云海——这是记忆空间！

"欢迎来到我的游乐场。"00号的声音在云海中回荡，"这里藏着创造者最不想让你们知道的秘密~"

云海翻腾，幻化出三千年前的景象：年轻的沈柯寒站在十二具水晶棺前，每个棺内都沉睡着与李元相貌相似的少年。但诡异的是，画面角落还站着第十三个人——一个模糊的银发身影。

"第...十三个实验体？"李元试图靠近，景象却突然切换。

这次是剑宗禁地，凌霜正将寒玥剑插入祭坛。她身后站着司空晦，手中捧着团紫黑色能量。"师姐，"他的声音充满蛊惑，"只要融合这个，我们就能超越老师..."

记忆再次跳转：沈柯寒在实验室暴怒，将系统核心摔成十二块碎片。"你们每个人都只配得到一部分！"他对着跪地的司空晦怒吼，"永远别想获得完整力量！"

00号的笑声从四面八方传来："有趣吧？创造者才是最大的骗子~"

李元突然明白了一切：沈柯寒为了防止系统被滥用，故意将核心分散。而司空晦寻找三千年，就是为了集齐所有碎片！

"哥哥，你知道最可笑的是什么吗？"00号的身影在云海中凝聚，"创造者临死前，把最重要的第十三块藏在了..."

记忆场景突然崩裂！寒玥-凌霜的声音穿透云层："李元，回来！"一道冰蓝剑光劈开记忆空间，将李元的神识强行拉回现实。

剑宗密室已面目全非。刘清音半跪在地，手中光剑黯淡无光；寒玥-凌霜的灵体布满裂纹；而00号琉璃正飘向半空，与司空晦完全体开始融合！

"阻止他们！"寒玥-凌霜将断剑插入地面，"用记忆共鸣！"

李元立即明白她的意思。他一手握住水晶柱，一手拉起刘清音。三人构成三角阵型，共同激活剑宗禁地的古老阵法。

整个密室亮起无数光纹，组成复杂星图。00号发出刺耳尖叫："不！这是凌霜的..."

星图投射出凌霜最后的记忆：垂死的她将某个东西封入寒玥剑，正是...第十三块系统核心碎片！

"原来一直在我体内..."寒玥-凌霜露出恍然之色，"难怪裘幽要控制我..."

融合进程突然中断！司空晦完全体痛苦扭曲，00号琉璃也从半空坠落。李元趁机启动系统最终协议：【检测到全部核心碎片，开始强制整合】。

水晶柱爆发出耀眼光芒，十二实验体的虚影纷纷脱离司空晦，回归本体。00号晶体从琉璃额头弹出，被李元一把抓住！

"结束了，弟弟。"

就在李元要捏碎晶体的瞬间，琉璃突然睁开眼："等等..."她的声音恢复清澈，"00号的核心...是你小时候的..."

记忆碎片突然涌入：年幼的李元抱着双胞胎弟弟哭泣，而沈柯寒在一旁摇头："他的恶念基因太强，必须封印..."

李元的手微微颤抖。原来00号不是敌人，而是弟弟被污染的善良面！

司空晦完全体趁机挣脱束缚，化作紫黑流星冲向天际："你们阻止不了新世界的降临！"

随着他的逃离，剑宗恢复平静。但所有人都知道——最终的决战只是推迟了。

琉璃彻底清醒，虚弱地摸着额头金纹："00号在我记忆里...留了东西..."

寒玥-凌霜的灵体开始消散："三天后月食之时...他会在归墟完成融合..."

刘清音握住李元的手："现在我们知道真相了...系统本就是为了..."

她的话被突然出现的空间裂缝打断。07号的机械手臂伸出裂缝，扔出个金属箱："用这个...对付..."手臂突然被紫黑能量腐蚀，缩回裂缝深处。

李元打开箱子，里面静静躺着十二枚芯片——正是当年沈柯寒分给十二实验体的系统碎片！
