# 第六十章 钟声为号

血色月光笼罩着葬仙峰顶，李元和刘清音沿着墓碑下的阶梯深入山腹。阶梯两侧的岩壁上镶嵌着无数水晶碎片，每一片都映照着不同的时空片段——有沈柯寒教导少年实验体的场景，有凌霜练剑的身姿，甚至还有...李元自己站在实验室的画面？

"这些是记忆结晶。"刘清音轻触一片水晶，里面立即传来凌霜的声音："师尊，07号的行为越来越可疑..."

寒玥剑突然剧烈震颤，挣脱刘清音的手，直刺向某块较大的水晶。剑身没入晶体的瞬间，整个山腹亮如白昼！隐藏的全息影像自动播放：

沈柯寒站在手术台前，台上躺着少年模样的07号。"记忆清洗程序启动。"沈柯寒的声音充满疲惫，"希望这次能消除裘幽植入的指令..."

影像突然扭曲，切换至黑暗的实验室角落。一个与李元相貌相同、但眼神阴鸷的少年正在修改某个仪器参数。"13号实验日志："他对着空气说道，"第742次尝试，老师依然不肯交出系统最高权限..."

"那是...未来的你？"刘清音倒吸一口凉气。

李元尚未回答，阶梯已到尽头。眼前是一个圆形石室，中央悬浮着两具水晶棺——左边是沈柯寒，右边是位银甲女子。令人毛骨悚然的是，沈柯寒的胸口插着把匕首，而匕首柄上刻着"07"的数字！

"凌霜师姐..."寒玥剑灵显形，跪倒在银甲女子的棺前，"原来您一直在这里..."

李元走近沈柯寒的水晶棺，系统突然发出刺耳警报：【检测到本体生命信号】！棺中的"尸体"猛地睁眼，枯瘦的手指抓住李元手腕：

"终于...等到你了..."声音嘶哑得不似人类，"小心...07号是..."

石室突然剧烈震动！十二道光柱的能量在天花板上汇聚成漩涡，一个熟悉的身影从中降下——是07号，但此刻他的机械义眼泛着紫光，手中握着与沈柯寒棺中相同的匕首。

"真遗憾，你们还是找到了这里。"07号的声音混合着电子杂音，"00号大人说得对，09号总能破坏计划。"

寒玥剑瞬间指向07号咽喉："叛徒！当年就是你害死师尊！"

07号不躲不闪，任由剑锋刺入脖颈——没有血流出来，只有电火花噼啪作响。"纠正一下，"他机械地微笑，"我既是07号，也是13号...是裘幽最成功的作品。"

真相如惊雷炸响：07号就是未来堕落的李元！是他回到过去修改了历史，在沈柯寒体内植入致命病毒，又伪装成助手潜伏三千年！

"不可能..."李元后退半步，"系统怎么会认不出..."

"因为系统本就是我的造物。"07号举起匕首，"准确地说，是未来的你为了赎罪创造的。"

石室四壁突然浮现血色符文，组成巨大的炼化法阵。07号启动控制台，两具水晶棺开始下沉："00号需要创造者的灵魂碎片完成融合，而你们...将是最后的祭品！"

刘清音挥剑斩向控制台，却被突然出现的能量屏障弹开。寒玥尝试冻结法阵，却发现剑身上的紫光正被阵法吸收——金字塔中的能量本就是陷阱！

"没用的。"07号按下最后一个按钮，"这是用你的基因设计的专属牢笼。"

千钧一发之际，沈柯寒的"尸体"突然暴起！他枯瘦的手指插入控制台缝隙，强行逆转了阵法流向："李元...现在！"

李元本能地掏出镇魂钟，全力敲响——

"铛！！"

青铜钟声如涟漪般扩散，所到之处时空为之凝固！07号的机械躯体僵在原地，眼中紫光剧烈闪烁："你竟敢...使用..."

钟声传至外界，十二道光柱中的三根突然扭曲变形！剑宗、药王谷和归墟上空同时浮现司空晦的虚影，发出痛苦嘶吼。早已埋伏的各派修士趁机发动总攻，法术光芒照亮夜空！

石室内，07号趁钟声间隙突然暴起，匕首直刺李元心口！刘清音闪身挡在前方，冰魄剑与匕首相撞——

"咔嚓！"

剑身断成两截，寒玥剑灵发出凄厉惨叫！07号的匕首余势不减，刺入刘清音肩膀，紫黑色能量瞬间蔓延。

"清音！"李元抱住倒下的刘清音，镇魂钟脱手滚落。

07号弯腰捡起铜钟："知道为什么使用它会折寿吗？"他抚摸着钟身上的裂纹，"因为这是用凌霜的剑心铸造的..."

沈柯寒突然扑向07号，枯朽的身躯爆发出最后灵力："李元，记住！真正的敌人是..."自爆的光芒吞没了后半句话，也将07号暂时击退。

寒玥剑灵用最后力量打开逃生通道："走...去剑宗...禁地..."她的灵体开始消散，"那里有...凌霜师姐留下的..."

李元抱起昏迷的刘清音冲入通道。身后，07号从爆炸烟尘中走出，半个机械身躯已经损毁："跑吧...00号大人马上就能..."

传送光芒中，最后映入李元眼帘的是沈柯寒水晶棺下的暗格——里面整齐排列着十二个小瓶，每个都标着实验体编号。而07号正虔诚地捧起标着"00"的那个...

天旋地转后，李元跌落在剑宗废墟。怀中的刘清音呼吸微弱，肩上的伤口泛着紫光。远处传来修士们的欢呼声——首战告捷，三处司空晦分魂已被重创！

但李元的心沉到谷底。07号的话、沈柯寒的警告、寒玥的遗言...这一切都指向某个可怕的真相。当他抬头看向剑宗禁地方向时，最深的恐惧得到证实：

一道血色光柱冲天而起，比十二光柱更加猩红可怖。光柱中悬浮的，正是被紫黑色能量完全侵蚀的...魔神手指！
