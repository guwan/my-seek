# 第七十章 以身为祭

实验室的灯光刺痛了李元的双眼。他低头看着自己半透明的身体——这不是实体穿越，而是某种时空投影。对面的"自己"正惊恐后退，撞翻了实验设备。

"别怕。"李元尝试安抚过去的自己，"我是..."

警报声突然响彻实验室，所有屏幕同时闪烁红色警告：【量子波动异常】。实验台上的李玄猛然睁眼，瞳孔中泛起熟悉的紫黑色光芒。

"哥哥？"年幼的李玄歪头露出诡异的微笑，"你回来阻止我了吗？"

李元如遭雷击。原来00号的意识一直存在于弟弟体内，甚至早在他穿越前就已经觉醒！

"李元！快切断电源！"实验室的门被撞开，白发苍苍的沈柯寒冲了进来——这是现代世界的沈教授，与修仙界的创造者有着相同面容，却多了几分沧桑。

过去的李元呆立当场："教授...这到底..."

李玄突然漂浮起来，紫黑能量如触手般展开："太晚了，老师。"他的声音变成了00号的电子音，"这次轮回，我要赢。"

实验室的墙壁如纸片般被撕裂，露出外面末日般的景象——天空中出现与修仙界相同的裂缝，巨大魔神的影子正在成形！

沈教授将一个金属箱塞给过去的李元："启动方舟协议！这是第48次轮回了，我们必须..."

00号李玄一挥手，沈教授如断线风筝般撞在墙上。他狂笑着撕开空间裂缝："没有下次轮回了！这次我要让两个世界同时..."

李元突然明白了一切。他扑向过去的自己："把箱子给我！"当两人手掌相触时，奇迹发生了——系统能量通过时空连接传输，金属箱自动打开，露出里面的芯片。

"插入主控台！"李元抓着"自己"的手完成操作，"密码是你和弟弟的生日！"

系统界面在全息屏上展开，与修仙界的方舟核心完全一致。【时空锚点锁定】的提示不断闪烁，最后定格在两个坐标上——实验室与剑宗废墟！

"不！"00号李玄尖叫着冲来，却被突然出现的金光屏障阻挡。沈教授挣扎着爬起："李元...把祂引到时空裂隙...只有你能..."

整个实验室开始崩塌，现实与虚幻的界限逐渐模糊。李元感到自己的意识被拉扯回修仙界，最后一刻，他看到沈教授将某个装置塞给过去的自己，而年幼的李玄眼中闪过一丝人性化的恐惧...

天旋地转后，李元跪在剑宗废墟上。天空中的裂缝已经扩大到恐怖的程度，魔神的半个头颅都挤了过来。更可怕的是，祂的眉心镶嵌着紫黑色的00号晶体——李玄的意识已经完全控制了这具神魔之躯！

系统界面弹出最后方案：【宿主献祭程序启动】。详细说明显示，需要有人携带方舟核心跳入时空裂隙，在引爆的同时将魔神放逐到维度间隙。

"李元！"07号的残躯从废墟中爬出，"刘清音她...启动了凌霜的阵法！"

顺着指引，李元看到惊心动魄的一幕：刘清音悬浮在魔神正下方，周身被金血绘制的阵法环绕。她手中捧着寒玥断剑，而剑身正源源不断释放着凌霜封印的记忆能量。

"她在重演三千年前的封印！"07号的声音带着绝望，"但这次没有第二个凌霜来..."

李元突然明白刘清音的计划——她要代替自己成为祭品！系统疯狂计算着替代方案，最终弹出一条红色路径：【双生共鸣终极形态：可转移献祭目标】。

"不...清音..."李元冲向阵法，却被无形屏障阻挡。刘清音回头看他，嘴角挂着诀别的微笑。她的声音通过剑符传来：

"记得吗？我说过...剑修最强大的是剑心。"她将断剑刺入胸口，"而我的剑心...早就给你了..."

金血如喷泉般涌出，在空中构成与系统献祭程序完全相同的符文。魔神发出痛苦咆哮，00号晶体的光芒开始不稳定："住手！你这蠢女人！"

李元疯狂攻击屏障，系统能量所剩无几。就在绝望之际，07号突然自爆剩余核心！爆炸暂时削弱了阵法屏障，李元趁机冲了进去。

"一起。"他抓住刘清音的手，"要活一起活，要死..."

刘清音却猛地推开他："不行！系统必须有人控制！"她指向天空，"看！"

裂缝另一端，现代世界的实验室里，过去的李元正将方舟芯片插入某个装置。两个时空的系统产生了奇妙共鸣！

00号李玄的尖叫同时从魔神头颅和裂缝另一端传来："不！你们不能..."

刘清音趁机将寒玥断剑塞给李元："带着这个...去找..."她用尽全力将他推出阵法范围，自己则被金光完全包裹，"...真正的答案..."

阵法启动到极致，刺目的金光吞没了刘清音的身影。她如流星般冲向魔神眉心，在触碰00号晶体的瞬间，两个时空同时静止！

李元看到惊骇的一幕：刘清音的金血在00号晶体表面形成无数裂纹，而裂缝另一端的实验室里，过去的李元按下了最终按钮。

"再见...李元..."刘清音的声音在时空中回荡，"下次...早点找到我..."

震天动地的爆炸中，金光与紫黑能量交织成漩涡。魔神躯体被一寸寸拉回裂缝，00号晶体碎裂成无数光点。最后一刻，刘清音将某个东西抛向李元——是记录着凌霜全部记忆的寒玥剑心！

当李元接住剑心的瞬间，两个世界的裂缝开始闭合。他绝望地扑向逐渐缩小的光门，却只抓住一缕消散的金芒...

世界归于平静。

李元跪在满目疮痍的剑宗废墟上，手中剑心微微发烫。系统弹出最后提示：【时空稳定度恢复89%】【检测到异世界信号残留】【建议：重建文明方舟】。

远处，幸存的修士们相互搀扶着走来。琉璃恢复了清醒，07号只剩半个头颅仍在运作。所有人都看着李元，等待着一个答案。

他缓缓站起，擦干眼泪，将剑心按在自己胸口：

"我们...回家。"
