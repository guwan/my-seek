# 第三十二章 临时搭档

黎明时分，沙漠的寒意尚未褪去，李元和白子游已经收拾好行装准备出发。昨夜那场战斗后，商队众人对这两位救命恩人既敬畏又疏远，只有驼队的老领队默默为他们准备了足够的饮水和干粮。

"往西北走三天，就能到达天机阁遗址。"白子游展开那张古老的地图，手指在某个标记上轻轻点了点，"不过据说那里已经被流沙掩埋了上千年。"

李元刚想回应，脑海中突然响起系统的提示音：

【联合任务发布：清除绿洲魔气】
【任务描述：西北方向五里处的绿洲水源被九幽魔气污染】
【奖励：系统能量恢复至50%】
【特殊要求：需与白子游协作完成】

"看来我们得绕个路。"李元将任务内容简略告知白子游，刻意隐去了系统相关细节，"我感应到西北有个绿洲被魔气污染了。"

白子游眉头一挑，玉箫在指尖转了个圈："巧了，那正好是我们必经之路上的最后一处水源。"他似笑非笑地看了李元一眼，"你的'感应'倒是很准。"

两人在沉默中前行，沙漠渐渐苏醒，热浪开始蒸腾。李元注意到白子游的步伐轻盈得不似常人，每一步都在沙面上留下极浅的脚印，而且每隔一段时间就会不自觉地摸向腰间药囊——那里装着那块系统组件。

"你之前说药王谷弟子失踪，具体是怎么回事？"李元打破沉默。

白子游的脚步微不可察地顿了一下："三十六名在外采药的弟子，三个月内陆续失去联系。最后找到的几具尸体..."他的声音低沉下来，"灵台都被某种力量侵蚀空了，就像被吸干的椰子。"

李元心头一震，这描述与剑宗那些被魔气控制的长老何其相似。他还想追问，系统突然发出警报：

【检测到高浓度魔气波动】
【坐标：正前方800米】

翻过一座沙丘，眼前的景象令人窒息——本该生机盎然的绿洲如今死气沉沉，棕榈树枯萎发黑，湖水泛着诡异的紫绿色。更可怕的是，湖边躺着十几具动物尸体，从野兔到骆驼都有，每具尸体上都长满了令人作呕的黑色菌斑。

"这是...九幽腐菌。"白子游脸色凝重，从药囊取出一副蚕丝手套戴上，"碰到一点就会侵蚀血肉。"

李元启动系统新解锁的物质分析模块，湖水成分立刻呈现在脑海中：【H2O占比63%，九幽魔气衍生物占比28%，未知有机物9%】。更令他心惊的是，分析显示湖底沉着三具人类骸骨，骨骼表面同样布满黑色菌斑。

"水源是污染源头。"李元指向湖中心冒泡的位置，"必须净化那里。"

白子游从药囊中取出几个瓷瓶："我有中和药剂，但需要直接投入污染核心。"他皱眉看着那些漂浮的腐菌，"问题是怎么过去..."

李元观察着湖面，突然注意到岸边有几根倒塌的棕榈树干。一个大胆的想法浮现在脑海："白兄，你相信科学吗？"

"什么？"

一刻钟后，白子游目瞪口呆地看着李元用树干、绳索和商队赠送的铜盆组装出一个简陋的"电解装置"。铜盆悬在两根树干之间，李元用断剑作为导体，将体内残存的所有火灵之力转化为电流导入水中。

"这叫电解，能把水分解成氢气和氧气。"李元解释道，汗水顺着脸颊滑落，"魔气应该会...咳咳...会附着在氢气上..."

随着刺耳的噼啪声，湖面开始剧烈翻腾，大量气泡涌出水面。白子游敏锐地注意到，那些气泡在阳光下呈现出不自然的紫色。他立刻吹响玉箫，音波将气泡集中导向岸边事先挖好的沙坑。

"现在！"李元大喊。

白子游将瓷瓶中的药剂倾泻而出，药液与气泡接触的瞬间爆发出刺目的白光。一股腐臭的黑烟升腾而起，被沙漠的热风吹散。湖水以肉眼可见的速度变得清澈，枯萎的棕榈树竟然也开始脱落黑色的树皮，露出下面新生的嫩绿。

【任务完成】
【系统能量恢复至50%】
【解锁新数据：司空家密探行动日志（片段）】

李元还没来得及查看新数据，白子游突然抓住他的手腕："你的灵力运行方式...不对劲。"他指尖泛起诊断用的绿光，"正常的周天循环应该是顺经脉而行，可你的灵力..."他眼中闪过震惊，"居然在体内形成了电路图一样的网状结构！"

李元暗道不好，这是他长期用系统辅助修炼留下的后遗症。正当他思考如何搪塞时，湖心突然传来异响——三具身披司空家服饰的骸骨浮出水面，其中一具手中紧握着一块玉简。

白子游用玉箫挑起玉简，上面刻着几行小字："监视目标已接触药王谷人员...确认持有天机盘碎片...等待进一步指..."最后几个字被腐蚀得模糊不清。

"果然是他们。"白子游冷笑一声，将玉简捏得粉碎。他转向李元，眼神变得锐利："现在，该告诉我真相了吧？你到底是谁？为什么司空家对你如此重视？还有..."他拍了拍腰间的药囊，"为什么你对天机盘的反应如此熟悉？"

李元深吸一口气，知道再隐瞒下去只会适得其反。他小心控制着系统，将一段关于九幽魔气的分析数据投射到沙地上："因为我和你一样，都在追查这股力量的源头。"

白子游盯着那些闪烁的数据符文，表情从怀疑逐渐变为震惊："这是...天机术？不，比那更..."他突然抓住李元的肩膀，"你就是古籍预言的'异数'对不对？来自天外的救世者！"

李元苦笑："没那么伟大。我只是个...意外卷入的倒霉鬼。"他犹豫片刻，决定透露部分真相，"你那块天机盘碎片，其实是一个更大系统的一部分。"

白子游眼睛一亮，正要追问，沙漠突然剧烈震动起来！湖中心出现一个漩涡，水流急速下降，露出湖底一个巨大的金属圆环。圆环中央刻着三个符号：眼睛、波浪和三角。

"监控模块的标记！"李元失声叫道。

圆环突然发出嗡鸣，一道光柱冲天而起，在百米高空展开成一面光幕。模糊的影像逐渐清晰——那是一个巨大的地下空间，无数身着司空家服饰的修士正在搬运某种仪器。画面边缘，几个熟悉的身影让李元血液凝固：剑宗执法堂的赵长老和另外几位本该在禁地之战中昏迷的长老，正对着一个背对画面的黑袍人躬身行礼。

"剑宗果然有内鬼..."李元喃喃道。

白子游倒吸一口冷气："那是...药王谷的'九转还魂丹'炼制室！他们怎么会在..."他的话戛然而止，因为画面中的黑袍人突然转身，露出一张他们两人都无比熟悉的脸——药王谷当代谷主，白子游的亲生父亲白无涯！

光幕突然熄灭，圆环沉入沙底，仿佛从未出现过。死一般的寂静中，白子游的脸色苍白如纸，手指无意识地摩挲着腰间的玉佩——系统之前检测到内藏监控阵法的那块。

"不可能..."他的声音轻得几乎听不见，"父亲他...三个月前就闭关了..."

李元不知该如何安慰，只能拍拍他的肩膀。就在这时，系统突然弹出一条紧急消息：

【警告：检测到远程监控激活】
【来源：白子游佩戴的玉佩】
【建议立即销毁】

李元瞳孔骤缩，正欲开口，远处的沙丘上突然出现了十几个黑点——是司空家的追兵！更可怕的是，领头之人手中举着的黑幡上，赫然绣着药王谷的标志！
