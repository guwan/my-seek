# 第三章 妖兽危机

清晨的青云镇笼罩在一层薄雾中，李元推开客栈窗户，深深地吸了一口气。经过一夜的修炼，《青云要术》中的基础心法已经让他体内的灵气运转更加流畅。系统界面上，他的境界也从"炼气初阶"变成了"炼气中阶"。

【日常任务更新：采集五株紫灵草（0/5）】
【任务奖励：初级解毒丹x3，任务点数x15】

李元伸了个懒腰，将系统奖励的隐匿符贴身收好。昨晚他特意检查了全身，确认再没有被标记的痕迹。那个神秘的司空老者就住在客栈对面的房间，整晚都没有动静，但李元总觉得事情没那么简单。

"先完成任务，再打听修士失踪的事。"他自言自语着走出客栈。

镇上的早市已经热闹起来，各种叫卖声此起彼伏。李元在一个早点摊前停下，用最后几枚铜钱买了两个热气腾腾的肉包子。摊主是个满脸皱纹的老妇人，见他面生，便多聊了几句。

"小哥是外地来的修士吧？"老妇人递过包子，"最近镇子外来的人可不少。"

李元咬了口包子，肉质鲜美多汁："是啊，听说青云山灵气充沛，适合修炼。"

老妇人左右看了看，压低声音："灵气是充沛，可也危险。上个月有三个像你这样的年轻修士进山采药，再没回来。"她摇摇头，"老刘家的儿子亲眼看见的，说山里来了群铁爪狼，凶得很。"

铁爪狼？李元心头一紧，这不就是第一天差点要了他命的妖兽吗？

"多谢婆婆提醒。"李元又买了几个包子揣在怀里，"那些修士最后去了哪个方向？"

老妇人指了指西北："听说是往飞瀑崖那边去了，玄天剑宗的弟子前几日还去查探过..."她突然住了口，警惕地看着李元身后。

李元转头，看到司空老者不知何时站在不远处，正冷冷地盯着这边。老妇人立刻低下头忙活自己的事，不再多言。

"早啊，前辈。"李元主动打招呼。

司空老者微微颔首："小娃娃起得挺早。"他的目光落在李元腰间的储物袋上——那是昨晚用任务点数在系统商城买的，"准备进山？"

"采点药草。"李元含糊其辞。

老者意味深长地笑了笑："西北方向最近不太平，建议你往东走。"说完，他转身融入了人群中。

李元眯起眼睛，这已经是第二次有人提到西北方向了。系统地图显示紫灵草在东边，但修士失踪的线索却在西北。犹豫片刻，他决定先去东边完成任务，增强实力后再调查其他事。

离开青云镇，李元沿着一条羊肠小道向东行进。随着海拔升高，植被逐渐变得稀疏，取而代之的是裸露的岩石和低矮的灌木。两个时辰后，他来到一片开阔的向阳坡地，这里生长着大量紫色的小草，在阳光下闪烁着微光。

"应该就是这些了。"李元对照系统提供的图像，确认这就是紫灵草。他小心地采集了五株，任务完成的提示立刻响起。

【任务完成！奖励初级解毒丹x3，任务点数x15】
【新任务发布：炼制初级疗伤药（0/1）】
【任务奖励：《基础炼丹术》x1，任务点数x20】

李元正查看着新任务，突然感觉背后一阵发凉。他猛地转身，看到三头铁爪狼不知何时已经包围了他，正缓缓逼近。与第一天遇到的那头相比，这几只体型更大，獠牙更锋利，眼中闪烁着嗜血的光芒。

"系统！有什么保命的东西吗？"李元在脑海中急问。

【宿主点数不足兑换强力道具】
【紧急机制激活：临时提升速度100%，持续时间30秒】

熟悉的暖流再次涌向四肢，李元毫不犹豫地冲向唯一没有狼阻拦的方向——一片茂密的森林。铁爪狼发出刺耳的嚎叫，紧追不舍。

李元在树林中左突右闪，借助速度优势暂时拉开了距离。但30秒转瞬即逝，当那股力量开始消退时，最近的一头狼距离他已不足十米！

"完了..."李元绝望地想着，突然听到前方传来水声。他拼尽最后力气冲出水声方向，眼前豁然开朗——一条清澈的小溪蜿蜒流过林间，溪边有块平坦的巨石。

更令人震惊的是，巨石上放着一堆整齐的衣物，而溪水中，一个窈窕的身影正在沐浴。那是个年轻女子，乌黑的长发湿漉漉地披在肩头，白皙的肌肤在阳光下泛着珍珠般的光泽。

李元愣神的功夫，铁爪狼已经追至身后。女子听到动静猛地回头，四目相对的瞬间，她的表情从惊讶迅速转为震怒。

"登徒子！"女子一声清叱，水面突然炸开，一道银光从水中飞出。李元只觉眼前一花，那女子已经披上衣衫，手持一柄寒光闪闪的长剑站在岸边。

三头铁爪狼似乎感受到了危险，停下脚步低吼着。女子冷哼一声，剑尖轻挑，三道剑气激射而出，精准地命中狼群。最前面的那头当场毙命，另外两只哀嚎着逃入林中。

李元目瞪口呆地看着这一切，直到冰冷的剑尖抵上他的喉咙。

"说！谁派你来偷看的？"女子凤目含怒，剑穗上玄妙的纹章随着她的动作轻轻晃动——那图案与司空老者的玉牌一模一样。

"误会！我是被妖兽追赶..."李元急忙解释，同时注意到系统界面突然弹出提示：

【关键人物识别：刘清音，玄天剑宗弟子】
【组队任务触发：共同击败铁爪狼群（0/1）】
【任务奖励：根据贡献度分配】

"铁爪狼？"刘清音微微蹙眉，剑尖稍稍后撤，"你一个炼气期，敢独自招惹它们？"

李元正要回答，林中突然传来此起彼伏的狼嚎声，听起来至少有十几头。刘清音脸色一变："狼群！"她狠狠瞪了李元一眼，"待会再跟你算账！"

话音未落，七八头铁爪狼已经冲出树林，将两人团团围住。这些狼比之前的更加壮硕，领头的那只额头上有一道闪电状的白色花纹，眼中闪烁着智慧的光芒。

"二级巅峰的铁爪狼王..."刘清音握紧长剑，声音略显凝重，"跟紧我，别拖后腿！"

狼王一声长嚎，狼群同时扑了上来。刘清音剑法精妙，每一剑都带起一道银色弧光，瞬间斩杀了两头狼。但更多的狼前赴后继，她渐渐有些应接不暇。

李元背靠溪水，手无寸铁，只能不断躲避。一头狼抓住机会扑向他的后背，尖锐的爪子已经碰到了他的衣服——

"小心！"刘清音回身一剑逼退那头狼，但自己却被狼王趁机在手臂上留下一道伤口。

李元看到她衣袖瞬间被鲜血浸透，心中一阵愧疚。他环顾四周，突然注意到溪边有几根枯木和干燥的藤蔓。

"给我争取一分钟！"他对刘清音喊道，同时冲向那些材料。

"你干什么？找死吗？"刘清音又急又怒，但还是咬牙挡在他面前，剑光如雨，勉强挡住了狼群的攻势。

李元用最快的速度将枯木堆成一个小型屏障，然后用打火机点燃了干燥的藤蔓。火焰迅速蔓延，形成了一道火墙。铁爪狼天性畏火，攻势顿时一滞。

"有用！"李元又从系统商城兑换了一瓶工业酒精，洒在火堆上。火焰猛地窜起一人多高，狼群惊恐地后退。

刘清音惊讶地看了他一眼："你那是什么法器？"

"待会解释！"李元抓起一根燃烧的木棍，"现在怎么办？"

"狼王不死，它们不会退。"刘清音撕下衣角简单包扎了伤口，"我需要一个机会..."

李元心领神会，突然冲出火墙，对着狼王挥舞火把："嘿！大家伙！过来啊！"

狼王被激怒，咆哮着扑来。就在它跃起的瞬间，刘清音身形如电，长剑化作一道银虹，直取狼王咽喉。狼王在空中勉强扭身避开要害，但前腿还是被剑气斩断，重重摔在地上。

剩下的铁爪狼见首领受伤，纷纷夹着尾巴逃走了。狼王挣扎着想要起身，刘清音上前一步，剑尖抵住了它的咽喉。

"等等！"李元突然喊道，"它好像想说什么..."

狼王金色的眼瞳中竟然流露出一丝人性化的哀求，它用剩下的三条腿艰难地比划着什么，最后用鼻子指向西北方向。

刘清音眉头紧锁："你是说...西北山谷有什么东西控制了你们？"

狼王点点头，然后痛苦地蜷缩起来。李元惊讶地看到，狼王额头上的白色花纹正在慢慢变黑，像是被什么污染了一样。

"九幽之气..."刘清音低声惊呼，后退了一步，"难怪这些铁爪狼会成群结队袭击人类。"

狼王发出一声悲鸣，突然用尽全力撞向一旁的岩石，当场毙命。李元和刘清音沉默地看着这一幕，空气中弥漫着诡异的气氛。

【组队任务完成！奖励分配中...】
【获得：《基础炼丹术》x1，任务点数x30】
【刘清音亲密度+10】

李元还没来得及查看奖励，刘清音的剑尖又指向了他："现在，解释一下你是谁，为什么会有这种奇怪的法器，还有..."她脸颊微红，"为什么偷看我沐浴！"

李元苦笑一声，正斟酌着如何回答，系统界面突然闪烁起来：

【警告：检测到九幽封印能量波动加剧】
【来源：西北方向15公里】

与此同时，刘清音腰间的玉佩突然亮起微光。她脸色一变："师门紧急召集令？"疑惑地看了李元一眼，"算你走运，我有急事。下次再见，定要你给个交代！"

说完，她收起长剑，身形几个起落就消失在树林中。李元长舒一口气，这才注意到刘清音刚才站立的地方，掉落了一块小小的玉简。

捡起来一看，上面刻着"玄天"二字，背面是一幅简略的地图，标注着西北方向的一个红点，旁边写着"禁地"二字。

"这就是修士失踪的地方吗？"李元若有所思。他抬头看向西北方向，隐约觉得那里的天空比别处更加阴沉。

回到青云镇时已是黄昏，李元刚踏入客栈，就听到掌柜正和几个客人议论纷纷。

"...听说玄天剑宗派了大队人马往西北去了！"
"又是那个鬼地方，上个月失踪的三个修士还没找到呢..."
"嘘，小声点，司空家的人还在楼上..."

李元心头一动，装作不经意地问道："掌柜的，西北方向有什么特别的吗？"

掌柜的看了看四周，压低声音："客官是新来的不知道，那边有个古战场遗址，据说埋着上古修士的宝物。但邪门得很，进去的人十个有九个出不来。"他摇摇头，"最近更怪了，连外围都开始出事。"

李元谢过掌柜，回到自己房间。他拿出《基础炼丹术》和今天采集的药材，准备尝试炼制疗伤药。但刚翻开书，系统界面突然弹出红色警告：

【紧急任务：阻止九幽封印破坏（限时72小时）】
【任务奖励：系统升级权限x1】
【失败惩罚：宿主将被九幽之气侵蚀】

李元倒吸一口冷气，这任务来得突然，惩罚更是可怕。联想到今天狼王的表现和刘清音的紧急离去，他意识到西北方向一定发生了什么重大变故。

"看来必须去一趟了..."李元喃喃自语，开始专心研读炼丹术。无论前方有什么危险，多一分准备就多一分生机。

夜深人静时，李元没有注意到，客栈对面的窗户后，司空老者正凝视着西北方向的天空，嘴角挂着诡异的微笑。他手中把玩着李元的打火机，而桌上摊开的地图上，西北古战场的位置被画上了一个血红色的叉...
