# 第三十三章 系统异常

司空家的追兵在沙丘上排成一列，黑幡在热风中猎猎作响。李元数了数，至少有二十人，每人腰间都挂着药王谷特有的玉牌。最令人不安的是，他们移动时步伐完全一致，仿佛被同一根线操纵的木偶。

"不对劲。"白子游的声音发紧，"那些玉牌...是药王谷精英弟子才有的本命符，怎么会..."

李元拉住他的胳膊："先躲起来！"两人迅速退到几块风蚀岩后面。李元启动系统扫描，数据立刻在视野中展开：【目标生命体征异常...灵力波动同步率98.7%...检测到控制型魔气感染】。

"他们被控制了。"李元低声道，"就像剑宗那些长老一样。"

白子游的手指深深掐进掌心："父亲...难道真的..."他的目光不自觉地飘向腰间的玉佩，那是他十六岁生日时父亲亲手所赠。

追兵突然停下，为首之人举起一面铜镜，镜面反射的阳光在沙地上扫过。当光束掠过李元他们藏身的岩石时，系统突然发出刺耳警报：

【检测到远程扫描】
【频率匹配：监控模块】
【来源：正东方向】

"被发现了！"李元猛地扑倒白子游，一道紫光几乎擦着他们的头皮掠过，将身后的岩石炸得粉碎。

白子游吹响玉箫，音波形成护盾挡住飞溅的碎石。他眼中闪过一丝决绝，从药囊掏出一颗猩红色的丹药："这是'焚血丹'，服下后半个时辰内功力翻倍，但之后会虚弱三天。"

李元刚要阻止，白子游已经吞下丹药。刹那间，他周身腾起血色雾气，玉箫发出的音波实质化成无数细如牛毛的红色丝线，朝追兵激射而去。

惨叫声此起彼伏，被红丝击中的追兵纷纷倒地抽搐。李元趁机启动系统战斗辅助，捡起地上碎石，用电磁加速原理将其投射出去。石块破空声尖锐如哨，精准击碎了三面黑幡。

【联合攻击模式激活】
【同步率82%...89%...93%...】

系统界面突然闪烁起来，李元感到一股奇异的共鸣在体内流转——那是白子游的音波灵力通过某种方式与系统能量产生了共振！两人对视一眼，不约而同地调整节奏，音波与电磁飞石交织成死亡之网，追兵一个接一个倒下。

当最后一名敌人倒地时，白子游突然喷出一口鲜血，踉跄跪地。焚血丹的反噬开始了。李元扶住他，正要查看伤势，系统界面突然剧烈闪烁，弹出鲜红的警告窗口：

【核心程序被入侵】
【安全协议失效】
【强制重启中...】

所有功能瞬间瘫痪，李元眼前一黑，险些晕厥。恍惚中，他听到白子游虚弱的声音："你的...天机盘...有问题..."

三分钟后，系统重新启动，但运行速度明显变慢：【重启完成...安全模式激活...部分功能受限】。李元尝试调出地图，却发现除了基础扫描外，大多数高级功能都被锁定了。

"见鬼..."他咒骂一声，扶起白子游，"能走吗？我们必须立刻离开这里。"

白子游脸色惨白，却坚持自己站立："东南方...三里有处岩洞...我上次采药时发现的..."

两人跌跌撞撞地穿过滚烫的沙地，身后倒下的追兵中，已经有几个开始抽搐着试图爬起来。李元回头看了一眼，寒意顺着脊背爬上来——那些人的眼睛完全变成了紫黑色，嘴角咧开到不可思议的弧度，露出非人的笑容。

岩洞比想象中宽敞，入口被风化的岩石巧妙遮挡。李元布置了几个简易警报装置，然后帮白子游处理反噬的伤势。当他撕开白子游被鲜血浸透的衣襟时，一块青紫色的诡异纹路映入眼帘——那纹路像树根一样从心口向四周蔓延，已经覆盖了大半个胸膛。

"这是...?"

"焚血丹的代价。"白子游苦笑，"每次使用都会侵蚀一部分心脉。"他艰难地取出几根银针，刺入自己穴位，"不过比起那些人..."他朝洞外方向努了努嘴，"我宁愿慢慢死。"

李元启动系统医疗扫描，数据让他心头一沉：【心脉损伤度47%...预计剩余寿命不超过三年】。更奇怪的是，扫描结果显示白子游体内有一种特殊的灵力结构，与系统能量场高度兼容。

"白兄，你平时修炼的是什么功法？"

"药王谷的《青囊经》，怎么了？"

李元没有回答，因为系统突然弹出一条新消息：【受限功能解锁...物质分析模块激活】。这个模块比之前的扫描更加深入，甚至能解析物质的分子结构。当李元无意中将分析对准白子游的玉佩时，屏幕上突然跳出一连串红色警报：

【检测到监控节点#07】
【信号特征：九幽魔气编码】
【最近通讯记录：12小时前】

李元死死盯着那条记录时间——正是他们在绿洲净化水源的时候！他猛地抓住玉佩："这东西一直在向外界发送我们的位置！"

白子游先是一愣，随后露出恍然大悟的表情："难怪...每次我快要查到线索时，司空家的人总会准时出现..."他颤抖着解下玉佩，"父亲给我的时候说...这是保命用的..."

李元将玉佩放在岩石上，用系统能量包裹住它。随着细微的碎裂声，玉佩表面出现裂纹，一缕黑烟从中渗出，在空中凝结成一个微小的眼睛图案，随即消散。

"监控法术被破了。"李元长舒一口气，"但对方肯定已经知道我们发现——"

洞外突然传来岩石滚落的声音。两人同时屏住呼吸，李元启动系统扫描，却只看到一片干扰雪花。白子游做了个手势，示意有人正在靠近洞口。

李元捡起一块边缘锋利的岩石，悄无声息地移动到入口侧面。脚步声越来越近，伴随着粗重的喘息。就在他准备出手的瞬间，一个熟悉的声音响起：

"李...李师兄？是你们吗？"

一个满身血污的年轻人跌跌撞撞地冲进洞穴，扑倒在李元脚下。他穿着剑宗弟子的服饰，腰间挂着已经断裂的玉牌——是林小凡！那个在葬神坑之战中幸存的剑宗弟子！

"林师弟？你怎么会在这里？"李元急忙扶起他。

林小凡的嘴唇干裂出血，眼神涣散："刘师姐...派我来...警告你们..."他死死抓住李元的手臂，"剑宗...药王谷...都是陷阱...不要去天机阁..."

他的身体突然剧烈抽搐，七窍中渗出黑血。白子游迅速施救，却为时已晚。林小凡用最后力气从怀中掏出一块染血的玉简："刘师姐...说...系统...被污染了..."

玉简落入李元手中的刹那，系统界面突然疯狂闪烁，大量乱码涌出。一段被加密的数据包自动解压，显示出刘清音匆忙留下的讯息：

「李元，剑宗禁地湖底有诈！执法长老们早就...」后面的内容被某种力量抹去了，只剩最后几个模糊的字：「不要相信系...」

系统突然陷入死机状态，所有界面变成刺眼的血红色，中央跳出一行李元从未见过的文字：

【主程序已接管】
【备用协议启动】
【继续执行原定任务】

这根本不是系统平常的语气！李元感到一阵恶寒，仿佛有双冰冷的眼睛正透过系统注视着自己。他下意识地想关闭系统，却发现控制权已经不在自己手中。

白子游注意到他的异常："怎么了？"

李元刚要回答，洞穴深处突然传来石块滚落的声音。两人警觉地转身，只见岩壁上一块原本毫不起眼的石头正缓缓移动，露出后面幽深的通道。一股带着古老尘埃的风从通道中吹出，隐约夹杂着机械运转的嗡鸣。

系统界面突然恢复正常，弹出一条新任务：

【隐藏任务触发：探索古代通道】
【奖励：系统完整度提升至65%】
【备注：此任务优先级高于一切】

李元与白子游对视一眼，都看到了对方眼中的震惊。这条通道显然不是自然形成的，而系统反常的表现更让人不安。但身后是司空家的追兵，眼前可能是唯一的生路。

"走吗？"白子游擦去嘴角的血迹。

李元深吸一口气，捡起林小凡的断剑："走。但这次..."他意味深长地看了一眼系统界面，"我们得留个心眼。"

通道深处的黑暗中，似乎有什么东西正在等待着他们。而李元不知道的是，在他系统深处，一段被标记为【主程序】的代码正在悄然改变着某些核心参数...
