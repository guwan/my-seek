# 第五章 奇葩奖励

李元回到青云镇时已是深夜，镇上的灯火大多熄灭，只有几家客栈还亮着微光。他肩膀上的伤口虽然不再流血，但被九幽魔气侵蚀的地方仍然隐隐作痛，像是有无数细小的冰针在血肉中游走。

【检测到宿主受九幽魔气侵蚀】
【建议立即使用净魔丹治疗】

系统商城中，净魔丹标价30点，而李元现在只有25点。他叹了口气，决定先回客栈用普通丹药压制伤势，等明天完成任务再兑换特效药。

推开客栈房门，一股淡淡的檀香味扑面而来。李元警觉地停下脚步——他记得自己离开时并没有点香。手按在青锋剑柄上，他小心翼翼地踏入房间。

"等你多时了。"一个沙哑的声音从黑暗中传来。

油灯突然亮起，司空老者——司空晦的弟弟正坐在窗边的椅子上，手里把玩着李元的打火机。老人脸上带着诡异的微笑，眼中闪烁着与年龄不符的精光。

李元全身绷紧，随时准备拔剑："前辈深夜造访，有何贵干？"

"别紧张。"老者摆摆手，"我若是想害你，刚才你进门时就动手了。"他指了指桌上的茶壶，"喝杯茶？"

"不必了。"李元站在门口没动，"前辈是来替兄长报仇的？"

老者哈哈大笑："报仇？我那兄长活了几百年，从不需要别人替他报仇。"他站起身，突然变得严肃，"小子，你知道九幽封印是什么吗？"

李元心头一跳，系统界面突然闪烁了一下，但没有新的提示。

"略有耳闻。"他谨慎地回答。

"上古时期，修仙界大能们将九幽魔界的入口封印在五个地方。"老者踱步到窗前，"青云山脉这个是最弱的一个，也是幽冥殿几百年来一直想打开的。"

李元皱眉："为什么要告诉我这些？"

老者转过身，眼中闪过一丝复杂的光芒："因为我虽然姓司空，却不像我兄长那样渴望九幽魔界的力量。"他从怀中取出一个小瓷瓶放在桌上，"这是净魔丹，能解你身上的魔气。"

李元没有去拿："代价是什么？"

"聪明。"老者赞许地点头，"代价是——离刘清音远点。"

这个要求让李元愣住了："为什么？"

"那丫头身上有玄天剑宗的大秘密，牵扯到九幽封印的核心。"老者叹了口气，"我兄长盯上她不是没有原因的。你若与她走得太近，只会引火烧身。"

李元盯着老者的眼睛，试图分辨其中的真伪："前辈为何要帮我？"

"就当是...对我兄长的小小报复吧。"老者露出一个苦涩的笑容，"他为了力量已经堕入魔道太深了。"说完，他走向房门，在擦肩而过时低声道，"丹药是真的，吃不吃随你。青云镇很快就不安全了，趁早离开。"

老者离开后，李元盯着那瓶丹药看了许久。系统扫描显示丹药没有问题，但他还是决定先用自己的方法治疗。李元加钱让客栈伙计帮忙找了一个院子，虽暂时没法住人，但是放炼丹炉炼丹还是可以的。

【任务更新：炼制净魔丹（0/1）】
【奖励：九幽抗性+15%，《初级符箓大全》x1】

李元拿出《基础炼丹术》和今天获得的药材，按照系统提供的配方开始尝试炼制。两个时辰后，当东方泛起鱼肚白时，他终于成功炼制出了一炉净魔丹——虽然成色不如司空老者给的那瓶，但系统认证有效。

【任务完成！获得九幽抗性+15%，《初级符箓大全》x1】
【当前九幽抗性：25%（轻度抵抗）】

回到客栈，丹药入腹，一股清凉之意流遍全身，肩膀上的刺痛感终于消退。李元长舒一口气，正准备休息，突然听到窗外传来一阵骚动。

他推开窗户，看到一队玄天剑宗的弟子正在镇中广场集结，周围聚集了不少看热闹的镇民。为首的是一名中年修士，正在向镇长询问什么。李元注意到刘清音并不在其中。

"看来封印那边情况不妙啊..."李元喃喃自语。系统界面上，九幽封印的倒计时还剩52小时，时间紧迫。

正思索间，房门突然被敲响。李元警觉地握住青锋剑："谁？"

"是我。"一个清冷的女声传来。

李元惊讶地打开门，刘清音站在门外，已经换了一身素白的便装，长发简单地束在脑后。她看起来有些疲惫，但眼神依然锐利。

"刘姑娘？你怎么..."

"进去说。"刘清音闪身进屋，迅速关上门。她环顾四周，目光在桌上的两个药瓶上停留了一瞬："你还会炼丹？"

"略懂一二。"李元收起药瓶，"玄天剑宗的人不是在镇上吗？你怎么..."

刘清音在桌边坐下，自己倒了杯茶："我是偷偷溜出来的。"她犹豫了一下，"封印那边情况比想象的严重。虽然暂时稳定住了，但最多只能支撑两天。"

李元心头一跳——这与系统给出的倒计时吻合。

"所以？"

"所以我需要你的帮助。"刘清音直视李元的眼睛，"你那些奇怪的法器和想法...可能正是我们需要的。"

【任务触发：协助刘清音稳定九幽封印（0/1）】
【奖励：系统升级权限x1，刘清音亲密度+30】

李元强压住心中的兴奋："为什么选我？玄天剑宗那么多高手..."

"因为宗门内有内鬼。"刘清音声音低沉，"这次行动如此隐秘，幽冥殿却提前设好了埋伏。而且..."她从怀中取出一块留影石，激活后显示出一段画面——几名黑衣人正在破坏封印，其中一人使用的赫然是玄天剑宗的剑法。

李元吹了声口哨："这可真是..."

"我暂时只相信你。"刘清音收起留影石，"因为你不是任何一方的人，而且..."她顿了顿，"你救过我。"

李元咧嘴一笑："所以我们现在是战友了？"

"暂时的合作伙伴。"刘清音纠正道，但语气已经不像最初那么冰冷，"我们需要找到三样东西来加固封印：月华精髓、玄铁晶和...一样特殊材料。"

"特殊材料是？"

刘清音脸上闪过一丝不自然："到时候再说。前两样我知道哪里有，但需要你的...特殊手段。"

李元若有所思地点点头。系统商城里正好有月华精髓，标价40点，而他现在的点数加上完成任务奖励的30点，刚好够买。至于玄铁晶...

"青云镇西边的老矿洞里有玄铁晶，但那里现在被一群铁甲蝎占据了。"刘清音说道，"我一人难以应对。"

"铁甲蝎？"李元回忆着《青云要术》中的记载，"怕火的那种？"

刘清音点头："但普通火焰对它们效果有限。"

李元露出神秘的微笑："我可能有办法。"他掏出手机——这个举动让刘清音明显愣了一下，"我需要准备一些东西。中午在镇西老槐树下碰头？"

刘清音犹豫了一下，点头同意。她起身准备离开，突然注意到桌上那本《初级符箓大全》："你从哪里得到这个的？这是玄天剑宗的入门教材。"

李元心里"咯噔"一下，表面却不动声色："路上捡的，看着有用就留下了。"

刘清音深深看了他一眼，没再多问，转身离去。

【刘清音亲密度+5，当前亲密度：35（略有好感）】

李元长舒一口气，立刻开始准备。他先用任务点数兑换了月华精髓——一小瓶银白色的液体，装在精致的水晶瓶中。然后研究起《初级符箓大全》，很快掌握了几个简单但实用的符箓画法。

【领悟技能：初级火符（可制造短暂的高温火焰）】
【领悟技能：初级遁符（短时间内提升移动速度）】

中午时分，李元准时来到镇西的老槐树下。刘清音已经等在那里，换了一身利落的猎装，腰间挂着一把短剑。

"你的法器呢？"她看了看李元空空如也的双手。

李元拍拍腰间的储物袋："都在这儿。走吧，路上我给你解释计划。"

前往老矿洞的路上，李元详细讲述了他的想法——用火符制造高温区域驱赶铁甲蝎，同时用特制的烟雾干扰它们的感知。刘清音听完后难得地露出一丝赞许的神色。

"你这些想法...虽然不合常规，但确实有可取之处。"她顿了顿，"你到底是什么人？那些奇怪的法器和知识..."

"一个喜欢解决问题的普通人。"李元避重就轻地回答，"话说回来，那个'特殊材料'到底是什么？"

刘清音的表情突然变得古怪起来，耳根微微发红："是...处子之血。"

李元差点被自己的口水呛到："什么？"

"不是你想的那样！"刘清音急忙解释，"只需要几滴，用于绘制特定的净化符文。这是...这是玄天剑宗秘传的封印术。"

李元强忍住笑意："所以...你是..."

"闭嘴！"刘清音恼羞成怒，加快脚步走到前面去了。

【刘清音亲密度+5，当前亲密度：40）】

老矿洞位于一座废弃的小山丘上，洞口被茂密的灌木半掩着，周围散落着锈迹斑斑的采矿工具。两人刚靠近，就听到洞内传来"咔嗒咔嗒"的声响，像是无数硬物相互碰撞。

"准备好了吗？"李元取出几张刚画好的火符。

刘清音拔出短剑，点点头。李元深吸一口气，将一张火符贴在洞口岩石上，注入少许灵力。符纸瞬间燃烧起来，产生一道近米高的火墙。

洞内的"咔嗒"声立刻变得急促，十几只足有家猫大小的铁甲蝎从黑暗中涌出。它们的外壳呈现出金属般的光泽，尾巴上的毒针闪烁着寒光。

"来了！"李元又激活两张火符，将最先冲出的几只铁甲蝎逼退。刘清音则剑光如电，精准地刺入铁甲蝎外壳的缝隙。

战斗持续了约莫十分钟，大部分铁甲蝎都被赶回了洞深处，只有几只特别凶悍的还在负隅顽抗。李元看准机会，将一个装满酒精的瓶子扔向最后几只铁甲蝎，然后丢出一张火符。

"轰！"酒精被点燃，爆发出一团巨大的火球。铁甲蝎发出刺耳的嘶鸣，纷纷逃窜。

"快！我们只有几分钟时间！"李元率先冲进矿洞。

矿洞内部比想象中宽敞，墙壁上镶嵌着星星点点的矿石，在昏暗的光线下闪烁着微光。刘清音迅速辨认出玄铁晶——一种深蓝色的结晶体，在众多矿石中格外显眼。

"那里！"她指向洞顶的一处，"需要挖下来。"

李元从储物袋中取出一把小镐，刚要动手，一阵剧烈的震动突然从洞深处传来。

"不好！是铁甲蝎王！"刘清音脸色大变，"快挖！我来挡住它！"

李元拼命凿击洞壁，终于撬下几块玄铁晶。与此同时，一头足有成年野猪大小的巨型铁甲蝎从黑暗中冲出，六只猩红的眼睛死死锁定两人。

"走！"刘清音一剑斩向蝎王的腿部关节，暂时阻滞了它的行动。李元抓起玄铁晶，两人拼命向洞口跑去。

蝎王发出愤怒的嘶吼，紧追不舍。眼看洞口就在眼前，蝎王突然喷出一股墨绿色的毒液！

刘清音回身挥剑，剑光形成一道屏障挡住了大部分毒液，但仍有几滴溅到了她的手臂上。她闷哼一声，动作顿时迟缓下来。

李元眼疾手快，一把抱住她冲出洞口，同时向后丢出最后两张火符。火焰暂时阻挡了蝎王的追击，两人跌跌撞撞地跑下山丘，直到确认蝎王没有追来才停下。

"你受伤了！"李元看着刘清音已经开始发黑的手臂，急忙取出净魔丹，"快服下！"

刘清音虚弱地摇摇头："没用的...铁甲蝎王的毒...需要特定解药..."

李元突然想起系统奖励的"防狼喷雾"——物品描述写着"对大多数毒素有中和作用"。他毫不犹豫地取出来，对着伤口喷了几下。

令人惊讶的是，黑色毒素真的开始慢慢褪去。刘清音惊讶地看着自己的手臂："这又是什么法器？"

"家乡特产。"李元咧嘴一笑，"看来我们两清了——你救过我，我救过你。"

刘清音轻哼一声，但眼神已经柔和了许多。她看向李元手中的玄铁晶："还差月华精髓..."

李元神秘地笑了笑，从储物袋中取出水晶瓶："巧了，我正好有。"

刘清音瞪大眼睛："你怎么会...这可是稀有材料！"

"我说过，我喜欢解决问题。"李元帮她站起身，"现在，能告诉我那个'特殊材料'具体要怎么取了吗？"

刘清音的脸"唰"地红了，一把推开他自己往前走："回镇上再说！"

李元笑着跟上，心想这个冰山美人脸红的样子还挺可爱的。然而他没注意到，远处的树丛中，一双眼睛正冷冷地注视着他们——正是客栈的老板。那人手中捏着一枚传讯符，正低声说着什么，目光始终没有离开刘清音的背影...
