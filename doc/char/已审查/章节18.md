# 第十八章 悬崖抉择

血月的光芒将玄天剑宗的山林染成一片猩红。李元和刘清音在密林中急速穿行，身后追兵的呼喝声越来越近。六块天元碎片在李元怀中发烫，仿佛在呼应着星移大阵中央那最后一块的召唤。

"前面是断魂崖！"刘清音突然刹住脚步，玄天剑横在身前，"没路了。"

李元回头望去，十几名紫眸修士已经形成包围圈，为首的赵寒手持一柄缠绕黑气的长剑，嘴角挂着残忍的笑意。"跑啊，怎么不跑了？"他剑尖指向李元，"司空大人说了，只要留你一口气就行。"

刘清音突然咬破舌尖，一口精血喷在玄天剑上。剑身顿时绽放出刺目银光，她双手掐诀，周身灵力如沸水般翻涌。"李元，记住我教你的剑诀。"她声音平静得可怕，"等会儿我说跳，你就跳。"

"你要干什么？"李元心头涌起不祥预感，系统突然疯狂报警：【检测到禁术波动】【危险等级：致命】

"剑影分光·万劫！"刘清音一声清喝，玄天剑竟一分为九，九道剑光如银河倾泻。这是玄天剑宗最高禁术，以燃烧寿元为代价，短时间内获得超越境界的力量。她的发丝以肉眼可见的速度变得灰白，但剑势却越发凌厉。

赵寒脸色大变："拦住她！"黑气化作盾牌挡在身前，却见九道剑光在空中划出玄妙轨迹，竟同时击中九名追兵眉心。被击中的修士连惨叫都来不及发出，便如木偶般栽倒在地。

"跳！"刘清音转身抱住李元，纵身跃向云雾缭绕的悬崖。赵寒暴怒的剑气擦着她的后背划过，在崖壁上留下一道三丈长的裂痕。

下坠的瞬间，李元看到刘清音嘴角渗出的鲜血和迅速失去光泽的皮肤。他拼命将她护在怀中，六块天元碎片突然自动拼接，形成一个半圆形的光罩包裹住二人。

"坚持住！"李元在呼啸的风声中大喊，系统界面突然弹出紧急提示：【检测到水体】【调整坠落角度】。他奋力扭转身体，让光罩以倾斜角度撞向崖底寒潭。

刺骨的潭水瞬间淹没二人。李元憋着气，死死抓住已经昏迷的刘清音。光罩在水下依然有效，形成一个气泡般的空间。借着碎片发出的蓝光，他看到潭底竟有一处散发着微光的洞口！

【发现异常能量源】【与系统匹配度87%】

求生的本能驱使李元向洞口游去。穿过狭窄的水道后，他们浮上了一个充满空气的洞穴。李元将刘清音拖上石台，颤抖着探她的脉搏——微弱但还在跳动。

"清音！醒醒！"他轻拍她的脸颊，系统医疗模块自动扫描后给出诊断：【生命力透支】【建议：灵力灌输】

李元毫不犹豫地将双手按在刘清音丹田处，将自己所剩不多的灵力渡过去。随着灵力输入，他注意到刘清音灰白的发丝逐渐恢复黑色，但系统能量槽却在急速下降。

"咳..."刘清音突然咳出一口淤血，缓缓睁开眼睛，"我们...还活着？"

"多亏你的禁术和碎片。"李元松了口气，环顾四周，"这里是..."

洞穴比想象中宽敞，四壁刻满了繁复的符文。最引人注目的是中央石台上的七边形凹槽，与拼接后的天元碎片形状完全吻合。更诡异的是，洞穴顶部镶嵌着七颗发光的晶石，排列方式与系统启动时的界面布局一模一样。

"这是...天元子的秘密洞府？"刘清音虚弱地支起身子，"看那些壁画！"

石壁上刻着一系列叙事壁画：第一幅是一个穿着奇装异服的男子从天而降；第二幅是他与七位修士共同对抗黑雾；第三幅则是男子站在发光的圆环中，似乎正要离去...

李元浑身一震——那圆环分明是他在物理课本上见过的爱因斯坦环，一种理论上可能存在的时空隧道！而画中男子的衣着，赫然是现代的T恤牛仔裤！

"我明白了..."李元声音发颤，"天元子也是穿越者！他留下的系统，就是为了..."

话音未落，洞穴突然剧烈震动，潭水翻涌。赵寒的声音透过水波传来："把寒潭抽干！他们肯定躲在下面！"

"没时间了。"刘清音挣扎着站起来，指向石台，"把碎片放上去，既然是天元祖师所留，或许..."

李元将六块碎片嵌入凹槽，碎片立刻亮起耀眼的蓝光。缺失的那一块位置则投射出一道虚影，直指洞顶——那里有一个隐藏的暗格！

"最后一块在这里？"李元难以置信地跃起拍向暗格，一块古朴的玉简应声而落。玉简上刻着四个小字："归途之钥"。

当李元触碰到玉简的瞬间，系统突然发出前所未有的提示音：

【最终协议解锁】
【宿主确认：李元】
【回归程序准备中...】

无数信息流涌入脑海，李元终于明白了系统的真相——这是天元子留下的时空锚点装置，目的不是帮助修炼，而是在九幽危机再次来临时，召唤另一个"天外来客"带来破局之法！

震动越来越剧烈，洞顶开始掉落碎石。"他们要进来了！"刘清音焦急地看向潭水，那里已经能看到法术的光芒。

李元握紧玉简，突然做了个大胆的决定。他将玉简按在石台中央，六块碎片立刻飞起环绕着它旋转。"系统，启动最终协议！"他大喊道，"但不是送我回去——我要召唤天元子留下的最后手段！"

【警告：非常规操作】
【确认覆盖默认指令？】

"确认！"

整个洞穴顿时被刺目的白光充满。在光芒中，李元看到石壁上的符文一个个亮起，最终汇聚成一扇光门。一个模糊的身影正从门中缓缓走出...

而就在这一刻，潭水轰然炸开，赵寒带着数十名修士冲了进来。他看到光门和身影，脸色瞬间惨白："不...不可能！那是..."

光门中走出的身影腰间，赫然佩戴着一枚与司空晦一模一样的紫金玉佩，只是上面刻的是"天元"二字。
