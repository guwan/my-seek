# 第四十一章 海市蜃楼


南海的晨雾如轻纱般笼罩着港口，李元望着停泊在岸边的巨型灵舟"碧海蛟龙号"，手指无意识地摩挲着藏在袖中的系统碎片。自从剑宗那场惊变后，他们马不停蹄地赶往南海，只为在00号苏醒前找到08号组件。

"船票买好了。"刘清音递来三块青玉牌，上面刻着"甲字七号舱"的字样。她换了一身素白长衫，冰魄剑伪装成一根玉簪插在发间，但眉宇间的忧色怎么也掩饰不住。"这艘船明日辰时出发，途经七座灵岛，终点是归墟附近的珊瑚城。"

李元接过玉牌，系统突然轻微震动：【检测到灵舟核心处有异常能量波动，疑似仿制系统子体】。他眉头一皱，正想提醒同伴，却见白子游从码头集市匆匆赶来，脸色异常苍白。

"不妙，"药王谷少主压低声音，"港口至少有三拨人在找'一男两女'的组合，其中一拨拿着司空家的紫铜罗盘。"他假装整理衣襟，露出腰间挂着的药囊——上面绣着的符文正微微发光，与系统产生共鸣。"我的护身符有反应，这艘船上有东西在召唤它。"

李元不动声色地启动系统扫描，发现整艘灵舟被一层极难察觉的紫色能量包裹，与剑宗那些被控制的弟子如出一辙。"我们可能上了贼船，"他苦笑道，"但这是前往南海的唯一途径。"

刘清音指尖凝聚出一丝剑气，在玉牌上刻下隐蔽的防护符文："兵来将挡。"



次日登船时，李元刻意观察了船员和乘客。那些水手动作过于整齐，笑容像是量产的模具；而乘客中至少有五人腰间挂着不同款式的"罗盘"，都是系统仿制品。最可疑的是船长——一个独眼老者，他的义眼偶尔会闪过紫光。

"三位贵客请随我来。"一个面容姣好的侍女引领他们穿过雕梁画栋的走廊，甲板上传来悠扬的琴声和笑声，完美得不像真实。"甲字舱有独立防护阵，可抵御六级风浪。"

李元注意到侍女手腕内侧有个细小的刺青——天机阁的六芒星标记！他假装绊倒，趁机触碰她的皮肤，系统立即分析出：【目标体内含0.3%魔气污染，意识被部分控制】。

进入舱房后，白子游迅速布下隔音结界："这艘船是天机阁的陷阱！那些乘客都是饵食，用来喂养海里的什么东西。"他从药囊取出一粒猩红丹丸捏碎，粉尘在空中组成南海地图，"古籍记载，归墟附近有'海市'现象，实则是上古大能制造的幻境牢笼。"

刘清音突然按住剑簪："有人监听。"

舱壁上的木雕纹路不知何时变成了眼睛图案，正诡异地转动着。李元立即释放系统干扰波，那些眼睛顿时渗出黑血，舱外传来一声闷哼。

"我们被发现了，"李元沉声道，"但奇怪的是，他们似乎不打算立即动手。"

【任务更新：调查灵舟核心】
【奖励：系统完整度+2%】
【警告：检测到00号能量波动】

系统界面突然闪烁起来，李元脑海中闪过一个画面——实验室爆炸瞬间，有个银边眼镜的反光。他甩甩头，那种被窥探记忆的感觉令他毛骨悚然。



子夜时分，灵舟驶入一片奇异的海域。月光下，海水呈现出不自然的靛蓝色，远处有朦胧的光晕浮动。李元三人潜行至动力舱附近，发现船员们正将一桶桶鲜血倒入某个装置。

"每月献祭百人，换取平安航行。"船长的声音从阴影处传来，他的义眼已经完全变成紫色，"三位贵客不在名单上，为何自投罗网？"

白子游弹出三枚银针，却被凭空出现的透明屏障挡住。整个船舱突然扭曲变形，金属墙壁软化如黏土，将三人分隔开来。李元感到脚下一空，坠入无尽的黑暗中。

【警报！遭遇高阶幻术攻击】
【启动紧急防护...失败...】
【建议：接受记忆检索可能找到突破口】

李元重重摔在一片洁白的地板上，刺鼻的消毒水味扑面而来——这竟是他就职的现代实验室！窗外阳光明媚，同事们如常工作，仿佛穿越只是一场梦。

"小李，把S-37样本拿来。"戴着银边眼镜的教授伸出手，镜片上反射着冷光。李元浑身发冷，这正是爆炸那天的情景！

幻境精准复现了每个细节：他转身去拿那个蓝色培养皿，教授悄悄调整了粒子对撞机的参数，然后...爆炸没有发生。教授突然摘下眼镜，露出司空晦的脸："你以为穿越是意外？不，是你体内09号碎片的自我保护机制。"

幻境再次变化，李元看到数千个培养舱，每个舱内都漂浮着一个"李元"的克隆体。司空晦的声音回荡着："三百次实验，只有你成功激活了系统。知道为什么选你吗？因为你的基因与沈柯寒匹配度99.9%！"

李元头痛欲裂，系统在意识深处尖叫：【不要相信幻象！】他拼命集中精神，回忆刘清音的剑意，终于在虚空中抓住一丝真实的寒意——是冰魄剑的气息！

与此同时，刘清音正经历着自己的噩梦。她站在剑宗废墟上，所有同门的尸体都睁着空洞的眼睛，重复着同一句话："容器就该有容器的自觉。"最可怕的是，她手中冰魄剑正在融化，露出里面机械结构的核心！

白子游则被困在药王谷的炼丹房，谷主——他的父亲——冷笑着揭露真相："你以为07号碎片是意外植入？不，从你出生起就是计划的一部分！"



当李元挣扎着破除幻境时，发现灵舟正被巨大的漩涡吞噬。真正的危机不是幻术，而是百年难遇的"灵力风暴"！甲板上乱作一团，那些被控制的乘客如傀儡般排队跳海，他们的血肉在海面形成诡异的符文。

"清音！子游！"李元在倾斜的甲板上奔跑，系统全力扫描着同伴的位置。一道闪电劈下，照亮了船头处对峙的两人——刘清音正用冰魄剑指着白子游的咽喉！

"他说你在利用我们！"刘清音声音颤抖，"说你早就知道系统会带来毁灭！"

白子游嘴角流血，却惨笑着："我在幻境里看到了药王谷的绝密记录...李元，你体内的系统根本不是沈柯寒造的，它最初是裘幽用来打开两界通道的工具！"

灵力风暴的中心突然裂开一道光门，将整艘灵舟吸入。在完全被吞没前，李元看到海底升起一座巨大的水晶宫殿——那才是真正的"海市蜃楼"，而宫殿穹顶处悬浮着一个蓝色光球，系统疯狂显示着：【08号组件检测！危险！危险！】

三人坠入光门的瞬间，李元终于抓住了刘清音的手，而白子游犹豫了一秒才握住他。风暴中，李元脑海中闪过最后一个画面：实验室里，司空晦将一枚芯片插入他的后颈，芯片上刻着"09→00"...
