# 第二十二章 初次交锋

药王谷的临时营地隐藏在赤焰山脉北侧的峡谷中。李元守在竹榻旁，看着药王谷首席医师白芷为刘清音处理伤口。那道黑纹已经从肩膀蔓延到锁骨，像活物般在皮肤下蠕动。

"九幽蚀心咒。"白芷眉头紧锁，银针在刘清音伤口周围排成北斗阵型，"幸好只是擦伤，若是直接命中......"她没说完，但李元明白言下之意。

刘清音苍白的脸上渗出细密汗珠，却硬是没哼一声。她的右手紧握着玄天剑，剑身微微震颤，发出清越的剑鸣，似乎在为主人分担痛苦。

"需要什么药材？"李元打开系统商城，"我这里有......"

白芷摇头打断他："寻常药物无用。此咒需以施咒者的血为引，配合......"她突然噤声，警惕地看向帐外。

帐帘被猛地掀开，一个浑身是血的药王谷弟子跌跌撞撞冲进来："白师姐！司空家......司空家攻过来了！"

远处传来连绵不绝的爆炸声，整个峡谷都在震颤。李元冲出帐篷，只见南侧山脊上黑压压一片紫袍修士，各种法术光芒如暴雨般倾泻而下。药王谷布置的防御阵法已经摇摇欲坠。

"不可能......"白芷脸色煞白，"他们怎么找到这里的？"

李元突然想起什么，一把扯开自己的衣领——胸口的蓝色印记正散发着微弱的黑光。"是追踪咒！"他猛地反应过来，"那支黑箭不仅是攻击清音，还在我身上......"

话音未落，三道凌厉的剑光破空而至，精准地落在营地中央。烟尘散去，露出三名身着紫金纹路袍服的金丹修士，呈品字形将李元所在的帐篷包围。

"天外来客。"为首的中年女修冷笑，"大长老有令，活捉你赏元婴丹一枚！"

帐篷内，刘清音强撑着站起来，玄天剑感应到主人战意，发出清越长鸣。她推开搀扶的白芷，一步踏出帐篷，剑尖直指三人："玄天剑宗刘清音，请赐教。"

中年女修面露讥讽："小丫头，你中的蚀心咒已经发作，还敢......"

她的话戛然而止。因为刘清音周身突然爆发出惊人的剑气，那些黑纹被硬生生逼退一寸！更令人震惊的是，她头顶隐隐浮现出一柄银色小剑虚影——这是剑意凝实的征兆，通常只有元婴剑修才能做到！

"一起上吧。"刘清音的声音冷如冰霜，"节省时间。"

三名金丹修士大怒，各自祭出法宝。一时间，黑幡遮天、毒砂漫空、飞剑如雨。刘清音却如闲庭信步，玄天剑每一次挥动都精准地击中最关键的一点。她的剑法不再拘泥于招式，而是带着某种浑然天成的韵律。

李元看得入神，系统突然弹出提示：

【检测到高阶剑意波动】
【记录中......】
【命名：天元剑意（残）】

"天元剑意？"李元一怔，随即恍然大悟——这一定是刘清音接受天元子传承时领悟的！他刚要细看分析数据，营地东侧突然传来惨叫。

三名黑袍修士不知何时突破了防线，正在屠杀药王谷弟子。他们手中拿着奇特的黑色圆盘，每杀死一人，圆盘就会吸收死者精血，发出妖异的红光。

"血祭法器！"白芷失声惊呼，"他们在收集能量重启召唤阵！"

李元立刻从储物袋掏出三颗改良版烟雾弹——这是他用系统科技结合修仙界材料特制的，不仅能遮蔽视线，还能干扰灵力感知。烟雾弹出手的瞬间，他同时激活了电磁脉冲戒指。

"砰！"

刺目的白光伴随着无形的波动扩散开来。三名黑袍修士的法器突然失灵，黑色圆盘冒出青烟。李元趁机冲上前，激光枪连射，精准击穿三人丹田。

"白医师！带伤员撤到北谷！"他回头喊道，同时用万象仪扫描整个战场。仪器显示，峡谷上方三千米处有一个异常能量点正在快速接近。

"不好！"李元瞳孔骤缩，"清音！小心上面！"

几乎在他出声的同时，天空骤然暗了下来。一只由黑气凝聚的巨掌从天而降，直拍向刘清音所在的位置！她刚与三名金丹修士交锋完毕，正处于旧力已尽新力未生的状态。

千钧一发之际，李元启动了最新兑换的量子位移器。他的身体瞬间出现在刘清音身前，双臂交叉硬接了这一掌。

"轰！"

李元如断线风筝般倒飞出去，撞穿了三顶帐篷才停下。他全身骨骼发出不堪重负的呻吟，系统界面疯狂闪烁红色警告。但最令他毛骨悚然的是，这一掌中蕴含的能量......竟然与系统能量同源！

黑气在空中凝聚成一个人形——司空晦！或者说，是他的一个分身。这个分身比李元在剑宗见到的更加凝实，半边人脸半边魔相，眼中跳动着猩红火焰。

"又见面了，天外来客。"司空晦的声音像是无数人同时在低语，"你的系统......发育得比预期要好。"

李元强撑着站起来，胸口蓝色印记灼烧般疼痛："你......到底是谁？"

司空晦没有回答，而是贪婪地盯着李元胸前的印记："S.K.H的量子锚点......终于成熟了。"他突然抬手，一道黑光射向李元眉心！

"铛！"

玄天剑及时格挡，刘清音挡在李元身前，嘴角溢出一丝鲜血。她的剑意虽然强大，但蚀心咒的折磨和连番激战已经让她到了极限。

"有趣。"司空晦眯起眼睛，"天元子的传承者......正好一起解决。"

他双手结印，周围空间突然扭曲。无数黑色锁链从虚空中伸出，缠绕向二人。这些锁链上刻满了与系统代码相似的符文，所过之处连光线都被吞噬。

李元咬牙启动万象仪，罗盘投射出一面蓝色光盾。锁链与光盾相撞，发出令人牙酸的摩擦声。令他震惊的是，光盾上的能量正被锁链快速吸收！

"没用的。"司空晦冷笑，"你的系统本就是我们世界的技术......"

他的话突然中断，因为一道金光从天而降，精准击中他的后心。司空晦分身发出不似人类的嚎叫，身体开始崩溃。

"药王谷镇谷之宝——神农鼎！"白芷站在远处高台上，双手托着一尊散发着金光的青铜小鼎，"邪魔外道，受死！"

更多的金光如雨点般落下，司空晦的分身终于支撑不住，化作黑雾消散。但在他完全消失前，李元清晰地听到他说："记住......系统不是你的朋友......它只是个牢笼......"

随着司空晦分身的溃散，来袭的司空家修士也如潮水般退去。药王谷弟子们发出欢呼，但李元的心却沉到谷底。他扶住摇摇欲坠的刘清音，看着她肩上再度扩散的黑纹，心中涌起前所未有的无力感。

"必须......去下一个节点......"刘清音气若游丝，"万象仪......指引......"

李元这才发现，万象仪不知何时已经自动激活，指向西北方向。罗盘表面浮现出一座雪山的虚影，旁边标注着三个古字："冰魄渊"。

白芷走过来，递给李元一个小玉瓶："这是压制蚀心咒的丹药，但最多只能撑七天......"她欲言又止，"要解此咒，唯有施咒者的心头血。"

李元默默收下药瓶，目光落在司空晦分身消失的地方。那里有一小团黑气久久不散，隐约形成某个符号——正是"S.K.H"三个字母的变形。

这个发现让他如坠冰窟。如果司空晦——或者说九幽魔尊——真的与系统同源，那么天元子、穿越、乃至整个九幽危机背后，究竟隐藏着怎样的真相？

而更紧迫的问题是，刘清音只剩七天时间了。
